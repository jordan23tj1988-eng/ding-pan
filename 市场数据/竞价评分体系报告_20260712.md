# 竞价评分体系+闸门+全市场留档·落地报告（2026-07-12）

08号竞价命门agent优化②③④全部落地，外加竞价角度个股评分体系。四件套脚本全部A档零后视镜，口径与竞价池结算.py同构，已接入两条定时任务链路（傍晚18:00 / 早盘9:30）。

## 一、竞价分：怎么打的

`竞价评分.py {d}`（傍晚跑）：冻结当日竞价池发出版，每票打【竞价分0-100】。

- **公式**：分 = Σ 维度权重 × 桶值。桶值 = 0.6×该桶执1胜率 + 0.4×执1均涨映射（[-3%,+3%]→[0,100]）；桶查一年分桶库（n=2829），n<10的桶取池整体中性值。
- **维度与当前权重**（∝执行均涨区分度，每晚随库滚动自适应）：封单比0.45、炸板0.30、温度0.11、信号×连板0.07、连板0.04、信号0.02。竞价维度信息主要长在封单比和炸板上——一字/秒板本身区分度反而小（差仅0.12pp）。
- **每票同时给**：主导因子拆解（哪个桶加分/拖累）+ 明晨三情景（该信号×高开档的历史执1均涨/胜率）+ 闸门预标（"若明晨高开≥5%→放弃"）。
- 产出：`_学习/竞价评分_{d}.json`（分数唯一源）+ `竞价评分卡_{d}.html`（嵌auction页段一，已渲染目检通过）。

## 二、WF验证：评分有没有预测力（零后视镜）

`竞价评分WF验证.py`：每月只用该月**之前**的样本建分桶库，给当月池票打分，对照真实执行收益。评分函数与线上同一份代码（import共用），杜绝口径漂移。

| 指标 | 结果 |
|---|---|
| 月度RankIC均值 | **0.12**（11个月中10个月>0，唯一负月202607为半月样本n=89） |
| 三分位价差均值 | **+1.14pp/月**（10/11月为正） |
| 全期三分位（n=2278） | 低分 -1.04%/胜率25.0% → 中分 -0.97%/39.7% → 高分 **+0.01%/45.9%**，单调 |
| 闸门内三分位 | 低分-0.45% / 中分+0.75% / 高分+0.61% —— 区分度减弱，评分与闸门信息部分重叠 |

**结论与定位**：竞价分有真实、稳定的排序能力，但高分组绝对收益≈0——**它是池内排序器和环境仪表盘，不是荐票器**。追开盘吃肉靠闸门，评分管"同样可吃时先看谁"。

## 三、闸门：9:25的执行规则（优化②）

`竞价闸门.py {昨日d}`（早盘9:25后跑）：昨日评分池 × 今晨实开 → 今日可吃名单卡，自动注入auction「★今晨闸门」段。

- 规则唯一且铁：**高开≥5% → 必弃**（一年n=1357：-1.74%/胜率21.5%，13个月零翻车）；已封板→⊘追不进只观察；其余→✓可吃候选（按竞价分排序+档内历史预期）。
- 07-09池backtest演示：可吃7只均收**+2.59%** vs 全池-0.17%（当天放弃的5只高开≥5票均收-4.02%）。
- 结算联动：竞价池结算.py 每晚自动出**闸门对账**（吃进部分vs全池）和**评分半区**（高分半vs低分半）——闸门和评分每天被结算验证或打脸，战绩不靠嘴。

## 四、全市场快照留档：C档转A档的开工日（优化④）
