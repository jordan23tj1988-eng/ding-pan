## 三、修改文件清单

### 1. `市场数据下载.py`
- **盘前误判修复**：`main()` 增加收盘前判定 (`is_before_close`)。
  - 原逻辑：今日涨停池与昨日相同 → 判为盘前滞后跳过。但只核「昨日」一次，核昨日接口失败时静默放行，陈旧数据被当当日数据。
  - 新逻辑：核昨日失败再核前天（双重校验）；收盘前(15:10 前)若数据已落盘，打印 `[警告] 数据可能不完整`。
- **龙虎榜双源回退**：新增 `fetch_lhb_direct(date_str)`。
  - 主源 `ak.stock_lhb_detail_em` 失败时，直连 `datacenter-web.eastmoney.com`（`RPT_DAILYBILLBOARD_DETAILSNEW`），自动翻页、列名映射为 akshare 兼容格式。
  - `requests.Session(trust_env=False)` 绕过系统代理（push2 域被墙）。

### 2. `分析引擎.py`
- **席位扫描双源回退**：`seat_scan()` 主源 `ak.stock_lhb_stock_detail_em` 失败后，调用新增 `_fetch_seat_direct(code, date)`。
  - 直连 `datacenter-web.eastmoney.com`（`RPT_BILLBOARD_DAILYDETAILSBUY` / `...SELL`），按 `OPERATEDEPT_NAME` / `NET` 字段映射回原列名，游资识别不变。
- 新增 `import requests as _requests`，保持 `socket.setdefaulttimeout(5)` 防挂起。
- **席位胜率加权修复（关键）**：`seat_quality()` 原按营业部**全称精确匹配** `_席位胜率库.json`，但龙虎榜明细接口（OPERATEDEPT_NAME）带「股份有限公司」后缀（如`开源证券股份有限公司西安太华路证券营业部`），而胜率库 key 不带（如`开源证券西安太华路证券营业部`），导致真实胜率几乎全失配、退化为固定兜底分。
  - 新增 `_norm_seat()` 剥离「股份有限公司/证券有限责任公司/证券有限公司/有限责任公司/有限公司」等后缀，建归一化索引 `_seat_idx`，匹配率从 3/23（13%）提升到 15/23（65%）。剩余未命中为「机构专用」等本无具体 key 的条目，走兜底分支属正常。

### 3. `概念排名.py`（新增）
- 消费根目录常驻底表 `concept_rank.csv`（名称,代码，372 个概念，由 `20260706/concept_rank.csv` 提升而来），遍历拉当日涨幅，输出 `YYYYMMDD/concept_rank.csv`（名称,代码,涨幅，按涨幅降序）。
- 数据源：首选直连 `push2his` kline（`90.BK{code}` / `90.{code}` 双 secid 尝试），回退 akshare `stock_board_concept_hist_em`。
- **健壮性**：先 `_probe_direct()` 探测一次，不可达则仅落概念清单（涨幅空）并早退，**不批量重试**——避免对不可达主机海量请求触发沙箱强杀（本环境 push2his 当前限流，故涨幅暂空；网络恢复或本地好网络运行即补齐）。已接入傍晚管道（步骤 2）。

### 4. 自动化（新增，非文件）
- **早间 竞价快照+竞价验证+数据下载**（每周一至五 09:30）：`竞价快照.py`（抓今日竞价）→ `竞价验证.py`（读 `_学习/候选_{T-1}.json` 拉实时行情验证昨日候选今日开盘兑现）→ `市场数据下载.py`（补全前一交易日龙虎榜/席位，盘前保护已启用不污染当日）。
- **傍晚 复盘完整管道**（每周一至五 17:00）：`市场数据下载.py`→`分析引擎.py`→`席位训练.py`→`公告跟踪.py`→`竞价训练.py`（★生成 `_学习/候选_T.json` 供次日早盘验证）→`生成复盘HTML.py`→`生成学习日记HTML.py`，单脚本失败不阻断后续。

> **修正记录**：初版自动化漏把 `竞价训练.py` 放入傍晚管道（它负责生成次日候选，是学习闭环的"产出端"），且 `竞价验证.py` 误放在傍晚（应在 T+1 开盘验证，用开盘价算高开/封板才准）。已按上述时序修正。

## 第二期 · 米氏框架升级（2026-07-07 下午）

> 基于《米开朗基瑞交易体系手册V2》对系统做核心升级。手册为系统唯一权威框架来源（已落盘 _学习/米氏框架_规则表.md + 知识库权威锚定）。

### 核心改动：给分析引擎装上"四层综合研判"灵魂模块
- **新增 `分析引擎.py` 的 `synthesize()` 函数**，把分层数据合成"阶段判断 + 演变推演"，而非各看各的。直接回应手册灵魂：环境→题材→周期→情绪 的**联动/过渡/转换**，四层共振还是背离。
- 输出落 `analysis.json["综合研判"]`，含 7 个子块：
  1. 量能台阶换算（量能→主线数/连板高度/龙头涨幅 + 2026.6+ 量能门槛，附"实际约束"消除理论值与实际门槛的歧义）
  2. 环境三态→总仓位映射（主升8-10成 / 混沌4-5成 / 退潮空仓，手册3.3）
  3. 周期定位（阶段1-5 + 周期级别，手册3.1/3.2）
  4. **四层共振/背离判定**（各层信号 + 共振结论 + 拐点预警明细）—— 这是"高手 vs 脚本"的分水岭
  5. 节点龙/2板定龙候选（用 最新价<20 + 流通市值<50亿 + 炸板≤1 过滤，手册5.2）
  6. 季节题材日历（当月关注 vs 当日主线，手册3.9）
  7. 异动红线占位（10天100%/30天200%，待接入历史K线）
- **`生成复盘HTML.py` 新增两张卡**：综合研判（米氏四层框架·灵魂）+ 节点龙/2板定龙候选，沿用现有 CSS。

### 知识库与规则表（供三角学习架构自学习）
- 知识库.md 追加"权威框架锚定"：米氏手册为唯一权威来源；并补充 2026 量化占比核实（35-42%，小盘>50%，与手册一致）。
- 新建 `_学习/米氏框架_规则表.md`：机器可读的 A档/C档 规则全集（量能台阶/情绪指标/周期仓位/主线题材/三式/节点龙/龙虎榜/买卖止损），作为学习子/审查子消费的规则库 + 后续自我升级基准。

### 7/7 实测判定（验证灵魂模块生效）
- 环境三态：**退潮** / 总仓位 空仓-0-2成
- 周期定位：退潮 / 中周期（按高度6板）
- 四层关系：**四层背离·弱**；⚠ 拐点预警"连板高度不低但跌停≥两位数→高位抱团松动，警惕瓦解"
