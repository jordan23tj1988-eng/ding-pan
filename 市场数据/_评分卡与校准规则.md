# 米氏短线·环境评分卡 + 动态校准规则

> 每日复盘任务用这张卡给市场打分→判定情景→推演。校准规则会随市场反馈每天修正（这是"自我学习"的载体）。
> 阈值来自《米开朗基瑞交易体系手册V2》第二/三/八部分 + 复盘推演三情景。

---

## 一、环境评分卡（每日按 summary.json 打分）

### 1. 量能台阶（米氏A1，最硬指标）
| 两市成交额 | 判定 | 分 |
|---|---|---|
| ≥3.5万亿 且较前日放量 | 主升延续（攻） | +2 |
| 3.2–3.5万亿 | 震荡蓄势 | 0 |
| 3.0–3.2万亿 且缩量 | 滞涨转弱 | −1 |
| <3.0万亿 | 退潮线下方 | −2 |

### 2. 情绪温度
| 条件 | 分 |
|---|---|
| 涨停>100 且 跌停<15 | +2 |
| 涨停60–100 常态 | 0 |
| 跌停>30 或 炸板率>0.5 | −2 |
| **连续2天两位数(≥10家)跌停** | −3（退潮实锤，空仓） |

### 3. 连板梯队
| 条件 | 分 |
|---|---|
| 最高板≥5 且 梯队金字塔递增（首板多、逐级收敛不断层） | +2 |
| 最高板3–4 且 梯队完整 | 0 |
| 梯队断层（高板孤票、2板稀少<3家） | −1 |

### 4. 题材主线（看涨停行业扎堆）
| 条件 | 分 |
|---|---|
| 有1–2个行业涨停≥5家（主线清晰） | +1 |
| 扎堆分散（各行业1–2家，混沌） | −1 |

### 情景判定（总分 → 情景 → 仓位）
- **总分 ≥ +4 且量能达标 → 情景A·主升**：仓位6–8成，顶主线节点龙/2板定龙，量化第一式套利。
- **总分 −2 ~ +3 → 情景B·震荡混沌**：仓位2–4成，只做量化套利日内 + 核心低吸，不追高，等新节点。
- **总分 ≤ −3 或退潮实锤 → 情景C·退潮**：空仓/防守，破5日K减半、破10日K清，退潮期禁套利。

## 三、评分卡自身的元规则（何时该改卡）
- 若某情景**连续3个交易日**推演与实际相反 → 说明阈值失真，需在校准区记录并微调对应分档。
- 大盘级别切换（如牛转熊）时，评分卡的量能绝对阈值要整体下移（熊市3万亿可能已是天量）——由任务判断并记录。
