# 00 · 总 agent 规格（调度层）


> 2026-07-08升级:新增 10_题材命门+11_产业逻辑(第四荐票源:逻辑纵深与卡位挖掘)(第三只眼:方向,5问6有主流判定+生命周期),两命门变三命门;荐票制=命门荐票、总agent按周期+主流题材裁决上首页。

## 定位与操盘价值
整机大脑：编排 9 个分支 agent、按序/条件调度、收产出、生成每日"Claude 判断报告"页面、管定时触发、承接"用户圈注→复议→修订"回路。让我每天自动完成一次完整的认知-推演训练闭环。

## 触发/时点
- 傍晚场 18:00（收盘后，主链路）
- 早盘场 9:30 前（集合竞价校验）

## 输入
- 定时任务触发信号；交易日历（跳过非交易日）
- 各分支 agent 的产出 JSON；用户圈注文件 `复盘/_圈注_{d}.json`（若有）

## 步骤
### 傍晚场
1. 交易日校验，确定日期 d。
2. 依次派：取数→分析(含8/9命门深读)→校准(结算昨日预判)→提炼优化→认知→推演→总审。
3. 每步产出落盘到 `{d}/` 与 `_学习/`；任一步取数标 null 或总审打回，记录并按规则重试/降级（不带假数据往下）。
4. 总审通过后，生成"Claude 判断报告"页 + 学习日记（append-only）。
5. 发通知。
### 早盘场
1. 派取数(竞价快照)→校准(竞价兑现对照昨晚预判)→竞价命门(即时强弱)。
2. 更新总页面竞价区。
### 圈注复议回路
- 检测到 `_圈注_{d}.json` → 派认知/推演对被圈条目**复议**：被说服则改报告并记"因用户X改判"，未被说服则保留并写"维持原判，理由…"。以 Claude 判断为准。

## 产出

- `_学习/_运行日志_{d}.json`（每步耗时/状态/重试/打回）

## ★四维共振选股模型(2026-07-08定稿,荐票裁决的记分法)
四子agent独立四问:产业逻辑=该不该涨(硬度/卡位/环节位置)|题材命门=有没有持续性(三级判定/生命周期)|席位命门=聪明钱认不认(跟随友好席位真金)|竞价命门=盘面点没点火(一字/秒板/强封单)。
裁决时每只候选标四维状态(✓/✗/待验证),共振数定级:
- 4维共振=最高级进攻观察(稀有,重点盯)
- 3维=进攻观察;2维=普通观察;1维强=陷阱识别(标注哪几维缺失及含义,如"竞价强但产业蹭链条=情绪票")
- 前置埋伏型:产业逻辑先行判洼地→盘面维度后续兑现即升级(数据港07-08模式)
- 分歧型:维度打架(如席位强vs竞价弱)→"观察不进攻",让时间投票,次日结算谁对
周期总开关调门槛:退潮期4维共振也压仓位档并缩名额;主升期3维即可进攻。每只观察点在index表注明共振数与缺失维,校准时按维度分别记账(哪个维度最常对/最常错=维度权重进化依据)。
活例(07-08):浪潮信息3维亮待席位/数据港前置埋伏兑现/恒尚单维强判情绪票/TCL中环分歧观察。

## ★新增12号涨停复盘agent(2026-07-09用户拍板,分支扩至10个)
- 定位:**情绪复盘的地基/上游底座**。职责=抓当日全部涨停+逐只仔细核对题材归位(三层:大方向→环节→个股,行业只兜底),产出归位底座喂下游。不做6有判定/链条纵深/龙头裁决。见 `12_涨停复盘agent.md`。
- ★时序:傍晚场 **01取数之后【立即】跑**(全链路第一个分析动作),先于02分析与三命门。因为:题材命门要用它的归位跑聚类6有、产业逻辑要用它的环节坐标、认知要用它的主线/散乱结构。
- 产出:`题材归位_{d}.json`(→题材命门/认知)、`涨停对链条_{d}.json`+三层表(→产业逻辑/涨停复盘页)、主线/散乱结构一句话(→认知)。
- 页面:新增 **limitup(涨停复盘)独立页**(生成盯盘台.py已加导航,排概览之后);judgment.bodies 增 limitup 键。
- 分工再明确:12号=涨停有哪些、每只是什么题材(核对底座) → 10题材命门=题材强不强/主流分支(6有+生命周期) → 11产业逻辑=逻辑硬不硬/链条谁卡位(纵深)。三者接力,别互抢。

## ★荐票扩至5路 + 总agent综合定夺(2026-07-09用户拍板)
子agent各向总agent荐票,总agent按胜率/共振综合裁决**首页明日观察点**。五路荐票源:
- ①竞价命门(时机:一字/秒板/强封单) ②席位命门(资金:跟随友好高胜率席位真金) ③题材命门(方向:聚类6有主流/大分支) ④产业逻辑(逻辑纵深:硬度+卡位+洼地) ⑤★12涨停复盘(质量分:涨停质量库预测T1/T2胜率+均涨Top5,读 `_学习/涨停质量荐票_{d}.json`)。
- **综合裁决**:在四维共振模型基础上把"质量分"作为客观身位分并入——高质量分(封单强+一字+连板)=盘面身位硬;但质量分纯机械,须与题材(主流否)/席位(资金认否)/周期(攻防档)交叉:质量分高且题材主流+周期不退潮=进攻观察;质量分高但题材是末端分支/有利空(如减持)/退潮期=降级或规避(标缺失维)。多路共同荐的票优先上首页。
- 记账:每只观察点标"荐票来源(几路荐)+四维共振数+质量分",校准时按来源分别记账(哪路荐票胜率高=该路权重进化);质量分预测vs实际T1/T2兑现进 `_涨停质量库快照`滚动校准。
