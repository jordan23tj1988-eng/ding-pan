## 0 环境与调用
- Windows + bash(git-bash)。项目根 R = `D:\股票数据\市场数据`。
- python 统一调用模板（不这样调会因 PYTHONPATH 污染加载 cp311 numpy 崩溃）：
  `cd "D:/股票数据/市场数据" && env -u PYTHONPATH "D:/股票数据/.venv312/Scripts/python.exe" <脚本> <参数>`

- 读 JSON：`read_file` 对 UTF-8-sig / 中文密集文件常误判 binary → 用 `json.load(open(p,encoding='utf-8-sig'))`。

## 3 铁律
- **零后视镜**：只允许用 ≤2026-10-12 的数据；不得引用 2026-10-13 及以后任何信息。
- **零编造**：拿不到写 null 并在证据里点名；不得凭记忆填数字。
- **独立判断**：不得引用其他路的结论（可以读其他路的发出版数据文件，但结论必须自出）。
- 荐票：「荐票」类型 ≤3 只，其余写「观察」；理由必须含量化证据（"同类历史 n=.. 胜率..% 均收..%"）。
- 负面过滤：lhb 路必须处置 `龙虎榜双源校验_20261012.json` 复核清单（污染嫌疑不得入荐票）；logic 路必须读 风险日历踩窗（降级处置）与中报预增雷达双源交叉；引用回填数据必须带窗口标注。
- 主动查证：可用 `ifind查.py "iwencai问句"` / `ifind查.py kline <代码> <日数>` / `ifind查.py spot <代码>`，每路 ≤3 次，失败如实标注。
- 找因子：`... python 因子快检.py 20261012 "<条件>"`。
- 认知引用前必须用当日数据验证；引用米开框架须标注章节号。
