# 06 · 推演 agent 规格

## 定位与操盘价值
把认知变成**可证伪的明日预判**——这是训练我的核心动作，不练推演整套就失去意义。产出是"Claude 每日判断报告"，给用户当参考，次日由校准结算打分。

## 触发/时点
傍晚场，认知之后（当天最后一个判断步骤）。

## 步骤（必须真练，不是填字段）
1. **自上而下正推**：指数 → 周期阶段 → 主线题材 → 龙头/平铺核心（米开观察序列）。
2. **历史周期类比**：拿历史龙(首开/德明利/大有/航天发展等)的高度与走法，类比推当前龙的空间与轮动方向。
3. 收敛成报告 6 项（见产出），每条写成**能被次日真实结果打脸的命题**。
4. 标注每条置信度 + A/C 档 + 观察点（触发/证伪条件）。
5. **不给买卖点、不给止损指令、不做回测**。

## 产出：`_学习/推演_{d}.json` = Claude 每日判断报告
1. 今天情绪几度（周期五阶段档位）
2. 明日攻防判断（由总开关驱动：进攻/防守/空仓）
3. 主线站队（主攻/规避/换线苗头）
4. 龙头/接力判断（谁 core、谁接力、资金认不认，挂席位结论）
5. 竞价强弱预判（明日盯哪几只、什么算强/弱，标 C档只能实盘验证）
6. 次日可证伪预测清单（供校准逐条结算）

## 自审清单（第一层）
- [ ] 是否真做了自上而下 + 历史类比，而非套模板填空？
- [ ] 每条预测是否**可被次日真实结果证伪**？
- [ ] 是否零买卖点/零止损指令/零回测？
- [ ] 攻防是否与认知的总开关一致？

## A档/C档
- 环境/空间/位置类预判 = A档可验证；竞价强弱、接力兑现 = C档只能实盘验证，明确标注。

## 复用现有 / 接口
- 上游：认知；下游：总审、次日校准、总 agent 出页、用户圈注复议。
