# 米开朗基瑞体系·量化规则清单

> 把手册里的规则按"**能不能用你现有数据因果回测**"分三档。所有判定式仅用**当日及之前**数据，零后视镜。
> 数据现状：`D:\股票数据\数据链路\data_link.py` 提供 **日线 + 通达信分钟历史**（`get(code, freq, adjust)`）。
> **没有**：集合竞价逐笔/竞价成交额明细、实时盘口大单、Level-2 tick。→ 依赖这些的规则**只能实盘用，不能历史回测**。

---

## A 档｜可直接回测（用日线/分钟历史就能算）

| # | 规则 | 量化判定式 | 数据需求 |
|---|---|---|---|
| A1 | 指数量能台阶 | `指数成交额 ≥ 3.5万亿 且 ≥ MA5(额)+3000亿` → 主升；跌破3.5万亿 → 滞涨 | 指数日线额 |
| A2 | 放量下杀/缩量回拉背离 | `连续≥2组：下跌日额 > 相邻上涨日额` → 危险，降水位 | 指数日线 |
| A3 | 回撤支撑位 | `支撑 = 前波高 − (前波高−前波低)×0.618`（备选0.713）；触及+当日放量止跌 → 低吸位 | 指数日线摆动点 |
| A4 | 情绪温度 | `封板率>80% & 最高连板≤4 & 跌停<15` → 攻；`跌停>30 或 封板率<66%` → 守 | 全A涨跌停/连板统计 |
| A5 | 连板天花板过滤 | `连板数 > 3` → 剔除（不做接力） | 全A日线（算连板） |
| A6 | 加速不接 | `个股近2日均放量拉升 或 隔夜美股对应板块已大涨兑现` → 次日不进 | 个股日线（美股需外源） |
| A7 | 位置过滤 | `距60日高点回撤 < X%`（高位）→ 不追；低位/结构位才要 | 个股日线 |
| A8 | 微盘切换先行信号 | `微盘股指数由跌转红/放量止跌 且 高位主线放量滞涨` → 风格切换预警 | 微盘指数+板块指数 |
| A9 | 题材梯队健康度 | `板块内 唯一最高板身位 & 2板≥1压制 & 首板数环比递增` → 强 | 板块成分+涨停统计 |

## B 档｜半可回测（需板块归类/龙虎榜，工程量大）

| # | 规则 | 说明 |
|---|---|---|
| B1 | 竞价最强方向 | 需竞价成交额按板块聚合——**历史竞价额难获取**，只能用开盘后前5分钟额近似 |
| B2 | 题材独立性 | `板块涨幅与美股对应板块相关性低 或 AI硬件跌而该板块逆势红` → 主线升级；需板块指数+美股映射 |
| B3 | 节点龙 | `个股首板日 == 指数结构拐点日 & 属当日最强主线` → 趋势持有；拐点判定主观 |
| B4 | 龙虎榜席位 | 西安太华路/高新成章路等量化席位入驻验证——需龙虎榜数据源 |

## C 档｜只能实盘、无法回测（核心第一式在此，务必知悉）

| # | 规则 | 为什么不能回测 |
|---|---|---|
| C1 | **量化第一式候选**：925竞价额进全市场Top5 或 ≥2亿 & 竞价涨幅≥5% & 低位 | 需**集合竞价逐笔成交额**，历史无 |
| C2 | **第一式买点**：开盘分时向上 + 盘口主动性大单 → 半路介入 | 需**实时盘口/逐笔大单**，历史无 |
| C3 | 第二式：盘中板块脉冲+消息 → 辨识度第1票半路 | 需实时分时+消息流 |
| C4 | 竞价三段（915/920/925）封单最大2只 | 需竞价封单实时数据 |

> **结论**：他招牌的"量化第一式"本质是**实时竞价+盘口的日内套利**，用你现有历史数据**跑不了回测**，只能实盘按规则手动执行。能用历史数据验证的是 A 档——即他的**指数量能择时 + 连板/位置/加速过滤 + 题材梯队**这套"环境与过滤"框架。
