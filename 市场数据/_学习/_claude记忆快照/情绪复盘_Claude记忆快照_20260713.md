## 1. sentiment_multiagent_project — 情绪复盘多agent系统(项目总纲)
=====================================================================

用户要把 A股短线情绪复盘重构成**多agent分层skill**,并明确了目标与铁律。

**★核心目标(2026-07-07 用户重大澄清,推翻旧版)**:把 **Claude 自己**训练成真正的A股短线情绪高手,不是把用户训练成高手、更不是每天吐报告的脚本。系统训练的是 **Claude 的认知/提炼/推演**。每日产出=**Claude 的思路与逻辑**,给用户当参考。
- 现阶段**不给买卖点、不做策略回测**,纯粹锻炼 Claude 的判断;用户在 Claude 真成熟前不会拿去真实操盘。
- **协作模型**:Claude 与用户是**两个独立判断主体**。Claude 出报告→用户读,对某判断有歧义就圈出来沟通→Claude 被说服则改报告,否则**以 Claude 自身判断为准**。报告对用户=参考,不是操盘指令。用户会投喂有价值文章供 Claude 学习。
- **认知地基=米开朗基瑞交易体系手册V2**(D:\股票数据\米开朗基瑞\米开朗基瑞交易体系手册V2.md,压435篇语料而成):量能台阶换算表/周期分类→仓位映射/量化套利三式/节点龙2板定龙/固定席位表/A档C档界线/止损仓位纪律。认知推演要用米开语言思考。

**架构**:
- 总agent(调度层):编排、按序/条件调各分支agent、收产出、汇总生成网页(盯盘台/报告),管定时触发。
- 分支agent(执行层):每个复盘环节=一个独立agent,职责单一、彼此解耦,便于单独调试替换。

**四点设计要求**:
1. 认知内核=吃透四层"关系/过渡/转换":环境→周期→题材→情绪(环境定周期空间/周期定题材持续性/题材承载情绪/情绪反馈环境)。重点是联动、阶段过渡、拐点提前识别(四层共振or背离)。叠加两命门:集合竞价 + 龙虎榜/席位洞察。
2. 方法=真实数据自我进化:每日复盘+推演,次日拿真实结果校准。对了沉淀进知识库,错了记打脸+降权。零编造、不事后美化、一个数都不许编。
3. 自主学习为主:主动网搜补缺口;只有搜不到/付费独有数据(真实竞价L2、顶级游资内部复盘)才找用户;用户投喂文章→消化进投喂库。
4. **铁律**:所有agent必须基于真实数据做审查,不许瞎编内容。

**已敲定架构(2026-07-07 v0.2)**:1总agent + 9分支 = 7流水线(取数/分析/校准/提炼优化/认知/推演/总审) + 2命门专家(竞价命门、龙虎榜席位命门,权重高于其余五维,双职责=历史预训练+每日深读喂认知)。
- 切分=功能流水线;命门破例独立成2个专家agent。
- 审查双层:每卡自审+总审agent动态打分(阈值可放宽,不因差1分误杀)。
- 傍晚场18:00主链路;早盘场9:30前完成(竞价快照+对照昨晚作战卡兑现)。
- 时序:先用今天真结果结算上一场(校准→提炼→提升认知),再做今天认知,绝不倒序。
- 提炼优化:攒够阈值才大提炼,未到持续标方向;只吃在案真实反馈;规则带**时效衰减/近因加权**(风偏约2周被量化学去,过期edge主动降权)。
