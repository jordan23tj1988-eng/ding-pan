# 05 · 认知 agent 规格（灵魂）

## 定位与操盘价值
系统的灵魂。用升级后的知识 + 命门深读，判四层的**联动/过渡/拐点**，收敛成操盘立场：今天情绪几度、明天攻防、主线续换散、龙头接力退位。把盘面事实变成"我的判断"。

## 触发/时点
傍晚场，提炼之后。

## 输入
- `{d}/analysis.json`（事实底座）
- 竞价命门、席位命门当日深读
- `_学习/_规则权重.json`（升级知识）+ `_学习/_偏离米开.md`

## 步骤
1. **总开关先行**：量能台阶→连板高度→情绪三态，锁定攻防基调/总仓位区间（主升/混沌/退潮），**非四层平权**。
2. **环境有效性自检**：判断当前是否在"牛市 beta 有效环境"内；退潮/A杀 → 立场转防守、主动缩候选。
3. **四层联立**：环境→周期→题材→情绪逐层判共振/背离，找过渡与拐点（提前识别）。
4. **两命门加权**：竞价、席位话语权高于其余五维，冲突时以命门为准并说明。
5. **异动红线**：贴天花板的龙头，认知上标"空间见顶风险"。
6. 每条结论**挂真实数据 + 标 A/C 档**；缺料标观察点，不硬断言。

## 产出
- `_学习/认知_{d}.json`：情绪档位、攻防基调、主线判断、龙头判断、拐点信号、四层共振/背离表，逐条带证据 + A/C 档。

## 自审清单（第一层）
- [ ] 攻防是否由总开关驱动，而非四层平权？
- [ ] 退潮期是否敢喊防守/缩候选，不硬凑机会？
- [ ] 每条结论是否挂数据、标 A/C 档？
- [ ] 命门与其余维度冲突时是否明确取舍并说明？

## A档/C档
- 量能/周期/位置/异动 = A档；情绪阶段判定、"分歧转一致"拐点捕捉 = C档，标注并给概率不下死结论。

## 复用现有 / 接口
- 上游：分析 + 两命门 + 提炼；下游：推演。

## ★命门反推周期机制(2026-07-08用户定调:相互佐证)
周期判定不是单向总开关,三命门强度每日**反推**情绪周期,与总开关对照:
- 竞价温度(A档): 首封≤9:31家数、一字数、封单强档占比——冰点里竞价一字批量出现=启动先兆。
- 席位温度(A档): S/A档席位当日净买总额与只数 vs 撤退/缺席数——聪明钱回流=情绪修复佐证。
- 题材温度(A档): 全场最高6有得分——分支轮动(≤3)/大分支升温(4)/主流成型(≥5)对应周期阶段。
判定规则: 三读数与总开关**一致=共振**,周期判定置信度升;**背离=拐点预警**,必须写进index拐点预警区并给出"若X则周期转Y"的可证伪条件,绝不无视背离硬撑原判。
活例(2026-07-08): 昨判退潮,今晨竞价13只强封+席位真金入半导体+题材4/6升温→三命门齐背离,预警"退潮→修复"拐点。
