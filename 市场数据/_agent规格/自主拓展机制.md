# 自主拓展机制（全系统"自主立项·自主进化"三层规范 v1.0，2026-07-12用户拍板）

> 源起=用户给11号产逻的三层方案(兜底触发/立项权+孵化区/错过复盘)。本规范把它按**各agent职能**推广到 ①竞价 ②席位 ③题材 ⑤质量 + cycle(05认知) + **总agent**。
> ★产业逻辑(11号/logic)不在本规范范围:其横切面扫描由另一程序实现;本机制文件名全部用"自主拓展*"错开"待深挖*",错过机会.jsonl共享(route字段区分,append-only两边兼容)。

## 一层·兜底触发（脚本零遗漏,R/自主拓展扫描.py）
`scan {d}` 每晚按职能横切面扫描 → `_学习/自主拓展清单_{d}.json`,各路agent对本路项**强制应答**→`_学习/自主拓展应答_{d}.json`:{item_id:{决定:"立项"|"不深挖",理由,专题id?}}。要么当晚立项深挖给结论,要么写明不深挖理由——等不到用户追问。
- auction:竞价池归因档位连续同向≥3日(该档位进不进评分/闸门)
- lhb:新活跃真席位(净买≥5000万,剔类别汇总/区间榜/通道席)不在分档库;真席位共现组合≥2次(协同资金)
- theme:归位标签计数≥3但四维无该线序列(线名归一or立6有判定)
- limitup:套票主导因子近5日≥3次(因子失效);选股增益连亏3日(荐票口径复盘)
- cycle:先行指标/温度分量250日分位≥95或≤5(极值必须专门判读,应答写进cycle段二判读card)
- ★master(裁决质量域):总账净值落后最佳子路≥1pp(裁决alpha复盘);错过机会近7日积压≥3条(master是miss主审);某子路增益连正3日(是否被裁决低配)

## 二层·立项权+专题孵化区（给权限）
`_学习/孵化区.json`={route:[{id,题,状态,判据(可证伪),截止,log:[{d,进展}]}]},状态机:**探索→小样本验证→提请拍板→固化成脚本 / 已证伪 / 搁置**。
- 每路agent每晚必须**新增或推进≥1个自主专题**(哪怕结论是证伪);中报预增雷达的诞生路径就是模板,但以后由agent自己发起。
- 防泛滥:**在研≤3/路**(tick告警);每专题必须带可证伪判据+截止日,`tick {d}` 超期未推进自动"搁置"(防僵尸专题,与防僵尸持仓同一哲学)。
- 页面孵化段:auction/lhb/theme/limitup各页新增"自主深挖·专题孵化"段(obs卡:题+状态chip+判据+最新进展),用户能看到、能打分;index新增"总裁决·自主进化"段(master专题+错过机会督办面板)。★cycle页也加独立段(2026-07-12用户点破修订,推翻原'融入段二'设计):"六 自主深挖·指标与阈值孵化"(清单应答条目(极值判读指向段二)+阈值/口径类孵化(三窗阈值年检/量能台阶口径漂移监测/温度分量钝化体检)+出页自检),认知迭代顺延七;埋在判读卡里=没有观察窗口。logic页由外部程序管。
- ★毕业通道接模拟盘:专题固化成脚本后,可转为该路交易规则试验(新闸门/新评分维度/新候选源),用自己账本的净值检验——闭环到"真实交易能力"北极星。

## 三层·错过复盘（从miss学习,闭环）
`_学习/错过机会.jsonl`(共享,route字段;来源∈{用户追问,audit自动,复盘自查});★核心创新=**拒绝也要结算**:`audit {d}` 自动回看2个交易日前应答中"不深挖"的项,标签计数≥2倍=打脸自动入账(引用当时拒绝理由示众),重跑去重。校准环节每晚核对;提炼环节把miss模式转成新触发规则——被打脸一次,就长一个自动触发器;master每周主审积压。

## 自检习惯规则（每晚出页前）
各路agent自问:**"如果用户明天问我'X有没有机会',现在的页面能不能直接回答?"**——答不上的X就是当晚该深挖的。总审抽查。

## 铁律
零编造(数据缺=该域跳过);拒绝理由必须可证伪(会被audit结算);孵化专题判据必须可证伪+带截止;隔离不破(各路只见自己路的清单项+孵化专题;master全见);miss入账不删除只标已消化。
