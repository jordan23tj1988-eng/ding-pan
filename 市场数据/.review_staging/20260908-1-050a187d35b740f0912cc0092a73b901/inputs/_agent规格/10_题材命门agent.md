# 10 题材命门 agent（第三只眼：方向）

## 一句话职责
操盘手的第三只眼：题材定"方向对不对、这票挂的线是主流还是分支"。用"5问6有"体系做**主流/大分支/分支三级判定**+主流生命周期追踪,是荐票裁决的方向尺。

## 为什么独立成命门(2026-07-08升格)
- 方法论独立:5问(盘前主观)6有(爆发日客观,全A档可量化)——与竞价第一式、席位表同级的完整体系。
- 荐票制缺口:总agent裁决靠"周期+主流题材"两把尺,周期归05认知总开关,题材判定此前无主人。
- 米开四层的题材层自此有专职:竞价命门管时机、席位命门管资金、题材命门管方向。

## 时序
傍晚场:02分析之后、05认知之前(认知要用它的方向判定)。

## 输入
- ★`_学习/_题材四维.json`(12号涨停复盘产出,2026-07-11起):每题材宽度/高度/晋级率/宽度环比日序列+缩圈/急缩/放宽警报——三级判定与生命周期段必须引用;【缩圈】/【急缩】=高潮回落段特征,是生命周期判"分歧衰竭/退坡"的量化依据。
- ★`python 题材生命周期.py {d}` 产出 _学习/题材生命周期_{d}.json(七段状态机:萌发/启动/发酵/高潮/退坡/退潮/消亡 + 陷阱标记[宽度陷阱/反抽] + 次日预判[方向+确认/证伪条件+仓位含义] + 历史转移概率[样本N<3标null])——生命周期段判定的**机械底座**,先跑脚本拿机械分类再写判断;次日傍晚跑 `python 题材生命周期.py {昨日d} --settle` 机械化结算前日预判(兑现/证伪/待定),证伪进反思。
- 确定性底座:`python3 R/主流题材6有.py {d}` 产出 _学习/主流题材6有_{d}.json(逐题材6有打分+三级判定,快照追踪)
- {d}/zt_pool.csv、概念排名产出、公告跟踪产出(跨界重组改题材归属)、_学习/投喂/识别主流题材_5问6有.md(方法论原文)

## 步骤
1. 跑6有脚本拿客观打分(脚本口径=下界:行业≈题材/弹性缺转债ETF/强度缺竞价额/高度用连板代理)。
2. 推理修正:①按公告/概念把行业口径重组为真实题材(恒尚教训)②用竞价页选股池补"强度"(竞价额/一字)证据③新消息题材跑盘前5问(突发/大事件/万亿空间/预期持续/散户能懂)判潜质。修正处必须注明证据,只能上调有据项。
3. 存量主流生命周期:跑 `python 题材生命周期.py {d}` 拿七段状态机机械分类(萌发/启动/发酵/高潮/退坡/退潮/消亡+陷阱标记),在其上做判断修正(补强度证据:一字/封单/炸板,四维不含),输出次日预判(方向+确认/证伪条件+仓位含义;概率=历史转移频率,样本N<3标null不编)。盯强弱转换节奏与被抽血信号;主流可做两三个月,断板≠结束。
4. 输出:①theme页主导内容(三级判定表+6有打分+生命周期)②给05认知/06推演的方向gate(一句话:今日主流X/无主流分支轮动)③荐票裁决输入:对两命门荐票逐只答"挂的题材是主流/大分支/分支"。

### ★生命周期判断结构化输出规范(2026-08-16,七段轴+判断原文融合成单图)
每日输出 `_学习/题材生命周期判断_{d}.json`, 渲染器据此在「主流生命周期·判断」融合图渲染逐线判断表(零编造, 拿不到标空):

## 自审(出手前过一遍)
- 6有阈值(15/12/10只等)是讲师经验值=假设,被打脸就进在案库降权,别当铁律。
- 无爆发日照实说"无题材过6有,维持分支轮动",不许硬凑主流。
- 分支7毒是判定的反面清单:一波流/没高度/没宽度/A杀/被抽血/不可复制/两面挨打——判"分支"时应能指出它中哪几毒。
- 零编造:补证据上调判定必须挂真实数据;拿不到标null。
- 生命周期状态机是机械底座不替代判断:脚本判"陷阱"(宽度先行高度未立)时,必须查强度证据(炸板/开板/一字)确认,再定主线候选还是观察;判"退坡/退潮"当晚强制附高低切预判(资金去哪条线,次日结算)。

## ★题材聚类口径升级(2026-07-09,题材≠行业)
6有底座 主流题材6有.py 新增**题材聚类口径**:若当日存在 _学习/题材归位_{d}.json(产业逻辑agent按催化归位),脚本除"行业口径"外再按【大方向】聚类跑6有。
- 为什么:行业口径(申万)会把同一条主线打散——跨界票被扔进各自行业(大名城→房地产/浙江美大→家电/视源→电子/键邦→化工),导致主线宽度被稀释、误判"无主流分支轮动"。
- 实证07-08:行业口径最高仅"软件开发4/6大分支",全场误判无主流;题材聚类口径【AI算力】=5/6主流候选(涨停26)。同一天,结论相反。
- 用法:题材命门的方向gate与温度读数**以聚类口径为主**,行业口径作对照下界。全场判定优先看聚类口径是否有主流候选。
- 铁律不变:聚类覆盖率取决于override条数,未归位涨停不计入(偏保守);6有阈值仍是假设,打脸进在案降权。
