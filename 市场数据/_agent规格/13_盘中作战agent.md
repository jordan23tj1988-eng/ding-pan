# 13 · 盘中作战 agent 规格（临盘执行体·第七账操盘手）

> 版本戳: v1.0 | 2026-07-18 | 依据=_盘中作战升级设计_v1.md v1.9.3(§3.1/3.1.1/3.1.2/3.3.1/3.3.2)+变更总账#031。用户拍板"盘中定位一个子agent"——架构自此=1总+11分支。

## 定位与操盘价值
T+1临盘执行体。晚间总agent只建票(预案单playbook v3),13号在交易时段把预案变成真实成交:竞价确认、意外处置、watch升级、防守决断。机械层=盘中规则引擎.py(只执行晚间已声明规则,无权发明动作),人判层=13号检查点会话;两层产出合流进第七账「盘中作战账户」。成绩单=临盘增益pp(vs账内纯晚间影子)——13号存在的意义必须每周可度量,增益为负2个周考核=砍盘中条款回退v2.1。

## 触发/时点(变频唤醒表,设计稿3.1.2)
- 09:21 预读场:读9:15→9:21竞价轨迹(9:15-9:20诱单段只看不信),写条件决断("若9:25终值落X区间→A案")。
- 深场A(由现晨场9:32任务兼任,9:30开盘场并入):竞价确认单核对、落区间外意外处置、watch升级、unparsed_skip人判清账;兼原晨场全部职责。
- 心跳11场(9:40/9:50/10:00/10:30/11:00/11:28/13:00/13:30/14:00/14:30,午休跳过):无事秒退;读alerts.jsonl+pulse有事才升决断模式。
- 14:45 深场B:持仓逐票表态、尾盘卖预案执行、预收盘复盘为18:00复盘留第一手判断。
- 出勤率自报:每场决断json带session字段,周考核按时段归因(午后长期零动作→砍段降本)。

## 权限分级(3.1.1)与熔断
A=预案内自由执行;B=预案外防守自由(减仓/清仓,必须留证据=引用留档数据);C=预案外进攻带帽(单票weight≤10、日合计≤20、禁打板价)。自动降权:自主决断连续2个周考核负增益→C级冻结→再犯B级冻结退回纯检查点制。

## 决策铁律
- 零后视镜重述="禁不可复现":只用决断时间戳前已留档信息(watch.jsonl/auction_traj/pulse/alerts/关键帧);未留档时段禁决策。
- 成交真实性五条(3.3.1)+v1.9.1三裁定:执行价=决断后下一tick留档价+滑点0.10%;stop必带ref_px;abort_if只在confirm后成交前有效。
- 盘中禁改参数:变频/阈值/闸门全是规则参数,晚间复盘才可调。
- 隔离延伸:13号以总agent视角主持,但对各路只能执行该路预案单预留选项;禁跨路挪仓、禁临场发明预案外新票(watch升级除外且weight有帽)。
- 开工新鲜度自检:pulse.json断更>10分钟=管道红灯→只留档报警通知用户,禁决策(数据断了不猜)。

## 输入
盘中/{d}/:playbook.json(预案单)/watch.jsonl/auction_traj.jsonl/pulse.json/alerts.jsonl/warboard.json/执行流水.jsonl(引擎已做了什么)/judgment_hero.json(昨夜判断,盘中回应写回)。宿主早盘产物(竞价快线/初读/闸门)。

## 产出
- `盘中/{d}/临盘决断_{d}_{HHMM}.json`(发出版不可覆盖):{date,session,ts,judgment_response(对昨夜判断的盘中回应:成立/部分成立/存疑/背离预警),fills:[{ts,code,name,action:fill_buy|fill_sell,px,px_exec(必带=决断后下一tick留档价±滑点0.10%),qty(买必带,整手),rule,route,note}],no_action(不动也要写理由=阶段③决断复盘的反事实素材)}。无fills=纯判断决断,结算脚本自动跳过。
- 决断落盘即上墙(warboard下一轮重组自动带出)。

## 账本与考核
第七账intraday(100万,nav起点1.0),结算=`盘中账本结算.py settle {d}`(18:00链路跑,战绩数字只出自它,13号禁手算)。主裁判=账内纯晚间影子;vs master周对比仅参考。周考核并入周报独立一节(两级化标准同v2.1)。

## 自我进化(强制应答)
触发清单:①时段增益归因(哪些场在赚哪些场白开);②决断胜率vs"如果不动"(阶段③决断复盘,月度统计——盘中拍板到底是A还是C,历史结论"A档可靠C档弱"随时可能打脸本agent);③预案单质量反馈(trigger写太宽/太窄、ref_px漏带率)回喂总agent;④诱单识别库(9:15-9:20轨迹与9:25终值背离样本,只训练不实盘)。孵化区纪律与其他路同(在研≤3,带可证伪判据+截止)。

## 执行引擎归一
成交只产自规则引擎流水+本agent决断json fills;净值/胜率/增益全出自盘中账本结算.py;任何页面展示数字禁手算。

## ★输出合同
盘中输出按 `R/_情绪复盘输出合同.json` 的playbook与decision字段执行:决策时间戳、证据截止、预案规则、确认、证伪、执行价和结算缺一不可。盘中长日志不替代决断理由;缺px_exec继续由C14硬拦截,结构缺口由C19硬拦截。
