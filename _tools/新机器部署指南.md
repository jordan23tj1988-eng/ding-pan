# 情绪复盘系统 · 新机器部署指南

> 2026-07-17 生成。目标:在一台新 Windows 机器上从 GitHub 仓库 `jordan23tj1988-eng/ding-pan` 完整恢复情绪复盘系统(脚本+数据+网页+技能+定时任务+Claude记忆),继续开发。
>
> ★**快捷通道**:同目录有 `新机一键还原.bat`(自动做完本指南第2~3步的文件还原)和 `新机Claude部署提示词.md`(喂给新机Claude自动做完第4~6步)。推荐走快捷通道,本指南作为原理说明和手动兜底。

---

## ⚠️ 第〇步 · 最重要的坑,先读这个

`同步到GitHub.bat` 是**单向镜像:本地 → 仓库**(robocopy `/MIR`)。
**新机器上 `D:\股票数据\市场数据` 还是空的时候,绝对不要先点同步 bat**——/MIR 会把"空目录"镜像到仓库,再 push 就把仓库内容全删了(虽然 git 历史能救,但很麻烦)。
**正确顺序 = 先从仓库把东西复制出来(第2步),再装自动同步(第7步)。**

---

## 1. 前置条件

- ★**旧机器必须先退役**(接力棒只能在一台机手里,否则两台机都在19:00推/MIR镜像会互相覆盖当天数据):
  ①旧机 Claude 里禁用 4 个 sentiment-* 定时任务(2026-07-17 换机时已做);
  ②旧机管理员命令行删 Windows 同步计划任务:`schtasks /Delete /TN "ding-pan每日同步" /F`;
  ③旧机最后手动点一次 `同步到GitHub.bat` 把最新状态推上去,之后不再让它自动跑。
- 安装 git,并保证能以 GitHub 账号推送 `jordan23tj1988-eng/ding-pan`(首次 push 时 Windows 凭据管理器会弹登录,或先 `git push` 一次验证)
- 代理:bat 里写死 `127.0.0.1:7897`,新机器代理端口不同就先改 bat 头两行
- Python 3 + pip
- Claude 桌面版,登录同一账号

## 2. 取回仓库并还原目录(方向:仓库 → 本地)

```bat
git clone https://github.com/jordan23tj1988-eng/ding-pan.git D:\股票数据\ding-pan仓库
robocopy D:\股票数据\ding-pan仓库\市场数据 D:\股票数据\市场数据 /E
mkdir D:\股票数据\同步GitHub
robocopy D:\股票数据\ding-pan仓库\_tools D:\股票数据\同步GitHub /E
robocopy D:\股票数据\ding-pan仓库\_tools D:\股票数据\同步GitHub\_extras\_tools /E
robocopy D:\股票数据\ding-pan仓库\skill D:\股票数据\同步GitHub\_extras\skill /E
robocopy D:\股票数据\ding-pan仓库\米开朗基瑞 D:\股票数据\同步GitHub\_extras\米开朗基瑞 /E
copy D:\股票数据\ding-pan仓库\README.md D:\股票数据\同步GitHub\_extras\
copy D:\股票数据\ding-pan仓库\requirements.txt D:\股票数据\同步GitHub\_extras\
copy D:\股票数据\ding-pan仓库\AGENTS.md D:\股票数据\同步GitHub\_extras\
```

(_extras 目录要还原齐,否则以后同步 bat 第3步会把空的 _extras 推上去覆盖仓库根文件。)

## 3. 装 Python 依赖

```bat
pip install -r D:\股票数据\ding-pan仓库\requirements.txt
```

## 4. 恢复 Claude 技能

在 Claude 里选定 `D:\股票数据` 文件夹后说:
> 读 `同步GitHub\_extras\skill\` 下各技能的 SKILL.md,用 save_skill 逐个注册:sentiment-review-system(必装)、finesse-ui、gsap-skills、taste-skill。

另外把参考文件复制回技能描述里写死的路径:
```bat
robocopy D:\股票数据\同步GitHub\_extras\skill\finesse-ui D:\skill\finesse-ui /E
robocopy D:\股票数据\同步GitHub\_extras\skill\gsap-skills D:\skill\gsap-skills /E
robocopy D:\股票数据\同步GitHub\_extras\skill\playwright-env D:\skill\playwright-env /E
```

## 5. 重建 4 个定时任务

在 Claude 里说:
> 按 `市场数据\_定时任务备份\` 里的 4 份 prompt 原文重建定时任务,taskId 和时间保持:
> - `sentiment-daily-review` 每交易日 18:00
> - `sentiment-morning-auction` 每交易日 9:20
> - `sentiment-weekly-training` 每周六 20:00
> - `sentiment-memory-snapshot` 每天 18:40(必须在 19:00 GitHub 同步之前)

备份文件头部有"⚠备份说明",正文就是 prompt 全文,逐字用。

## 6. 恢复 Claude 记忆

在 Claude 里说:
> 读 `市场数据\_学习\_claude记忆快照\情绪复盘_Claude记忆快照.md`,把里面每条记忆按原名导入你的持久记忆并更新 MEMORY.md 索引。

注意:快照**只含情绪复盘相关记忆**。自研战法(5分V6/V8/aAb)、缠论引擎/隧道画法等私有策略记忆按铁律不进公开仓库——如需迁移,在旧机器上把 Claude 记忆目录(`...\local-agent-mode-sessions\...\memory\memory\`)整个私下拷走(U盘/私有渠道),别走这个公开仓库。

## 7. 安装每日自动同步(最后一步)

确认 `D:\股票数据\市场数据` 内容已齐全后:
- 双击 `D:\股票数据\同步GitHub\同步到GitHub.bat` 手动跑一次,确认能 push 成功
- 双击 `安装每日自动同步.bat` 注册 19:00 计划任务

## 8. 验证

在 Claude 里说:
> 跑 `python3 市场数据/复盘一致性哨兵.py {最近交易日}`,再读 `_变更总账.md` 最近3条确认认知同步。

哨兵全绿 + 盯盘台网页能正常生成 = 部署完成。
