# 01 · 取数 agent 规格

## 定位与操盘价值
一切判断的地基。抓当日真实盘后数据 + 集合竞价数据，结构化成原始池。地基脏，后面全错——所以它的唯一使命是"真"与"全"。

## 触发/时点
傍晚场(盘后全量)、早盘场(9:25 后竞价快照)。

## 输入
- akshare 免费源(无需 token)；交易日 d。
- 需要的数据面：涨停池/连板梯队、跌停、炸板、龙虎榜(全市场)、量能(两市成交额)、指数量价、竞价量价快照。

## 步骤
1. `pip install akshare --break-system-packages -q`（沙箱重置需重装，可多试几次）。
2. 抓取上述各面 → 落 `{d}/` 原始文件 + `{d}/summary.json`。
3. 盘前脏数据护栏：与前一交易日完全相同 → 判为未更新，丢弃并标 null。
4. 竞价快照(早盘)：抓盯盘清单竞价量价 → `_学习/竞价快照_{d}.json`。
5. 缺数据：**先自己想办法找**(换接口/重试/其他免费源)，实在拿不到 → 标 null，写 `缺数据说明`。

## 产出
- `{d}/`（涨停池.json、龙虎榜.json、量能.json、指数.json…）+ `summary.json`
- `_学习/竞价快照_{d}.json`
- `_缺数据_{d}.json`（哪面缺、试了什么、为何缺）

## 自审清单（第一层）
- [ ] 每面数据是否非空且时间戳=今日？（否则 null，不沿用旧值）
- [ ] 是否触发盘前脏数据护栏？
- [ ] 龙虎榜是否**全市场**拉全（服务全局席位研究，不预筛）？
- [ ] 缺的是否如实登记、绝不用估算值填？

## A档/C档
- 盘后量价/涨跌停/龙虎榜数字 = **A档**(可复现)。
- 竞价逐笔大单/L2 封撤单 = **C档**(实时接口不稳、历史不可复现)——拿到即用，标 C档；拿不到标 null。

## 复用现有 / 接口
- 复用：市场数据下载.py、竞价快照.py。
- 下游：分析、竞价命门、席位命门、校准。
