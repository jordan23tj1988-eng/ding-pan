# 识别主流题材·5问6有体系（神光米广亮5课，2026-07-08消化）
来源:用户投喂《识别主流题材》PPT.zip(5篇课件PDF,254页)。与米开淘股吧复盘同属神光系,但这套是**题材层的系统方法论**,直接补我theme层的结构性缺陷。

## 一、数据地基(第1课,A档·历史统计)
- 牛市分4阶段:起步→确立→主升浪→最后强势。每阶段只有2-3个主流题材+核心领涨股。
- 各阶段跑赢指数比例(2007/2015):起步68%/71%,★确立53%/16%(二八最狠,机游趋势行情只有主流涨),主升83%/83%,最后强势18%/85%(07年57%个股下跌)。
- 熊市主流题材=沙漠绿洲:2024年90%个股下跌,但每月都有翻倍主流(新质生产力/低空/正丹/无人驾驶/华为)。
- 推论:**不参与主流=亏钱根源;抱住不动只有主升浪约3个月舒服**。

## 二、盘前5问(第2课,主观预判,B/C档只记不回测)
消息当晚问:①突发(公平性,所有人同时知道,非信息差)②大事件(产业颠覆/改变社会规则)③想象空间(★万亿级=主流潜质;千亿级=大分支——恒尚存储属此类)④预期持续性(时间预期+持续消息,买预期卖事实)⑤情绪(散户能懂能信能买能教)。

## 三、★盘面6有(第3课,爆发首日客观确认,全A档可量化!)
| 有 | 量化标准 |
|---|---|
| 宽度 | 题材涨停数:万亿成交≥15只 / 万亿以下≥12只 / 8000亿以下≥10只 |
| 强度 | 首日/次日竞价有一字板;一字数≈前日涨停数的1/10;竞价额:万亿以上≥20亿/万亿以下≥10亿 |
| 容量 | 有机构级容量票涨停:自由流通市值≥200亿(万亿以下100亿/8000亿以下50亿) |
| 弹性 | 资金类型齐全(埋伏/挖掘/接力/套利):20cm+30cm(可选)+可转债(可选)+ETF+换手连板都动 |
| 高度 | 出快速翻倍股且为5/10日涨幅第一:30cm 2.5天/20cm 4天/10cm 7天翻倍 |
| 换手 | 有买得到的换手高标(非全一字,如无人驾驶/小红书/雅下型) |

★判定流程:消息当晚5问(主观)→爆发首日开盘6有(客观)→确定主流后不犹豫,最重要是在车上。

## 四、分支7毒(第4课)
①一波流大概率大亏(布局→制造涨停吸跟风→合吹→接盘)②没高度没盈利空间③没宽度无赚钱效应④A杀无承接⑤随时被主流抽血(分支多散户资金,短线资金是最稀缺资源)⑥无周期规律不可复制⑦两面挨打(分支亏钱+主流踏空)。
- 同一模式用在主流赚钱、用在分支亏钱——不是模式错,是地方错。主流1个足够。
- 2025逐月主流参照:1月消费+机器人/2月DS+机器人/3月DS+机器人+深海/4月消费+贸易战/6月稳定币+中东/7月稳定币+雅下+创新药/8月算力+机器人。

## 五、主流周期结构(第5课)
- 真实主流周期≠单边梯形衰减,= **主升浪+补涨两段**(可调整半月再来一波,一个主流可做两三个月)。
- 可复制机会=强弱转换节奏:弱转弱/弱转强/强转弱/强更强。
- 游资分工:抓每阶段领涨羊/做小势(每周一次5-10%)/主升补涨切换/专做补涨。
- 底层原则=缠论:完全分类+不测而测(不预测只应对)。
