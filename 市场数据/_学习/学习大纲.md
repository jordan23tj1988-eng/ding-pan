# 学习大纲：把自己练成 A股短线情绪高手

> 目标：真正吃透 **环境 → 周期 → 题材 → 情绪** 四层的**关系、过渡、转换**，并对**集合竞价**和**龙虎榜/席位**有深刻洞察。
> 用法：学习子agent 每天按这七大板块做深度学习；审查子agent 按此对照打分；缺口部分我会向用户求材料。
> 铁律：只学能落地、能被市场反馈验证的东西；一切结论要么有数据支撑、要么标注为"待验证假设"；严禁编造。

## 一、七大学习板块（每天都要覆盖，不许只写流水账）

### 板块1 · 环境（大盘/资金环境）
- **要吃透**：两市量能台阶与主升/退潮的因果；指数结构（浪型/缺口/均线）；赚钱效应 vs 亏钱效应；连板高度天花板随环境变化；北向/两融/权重的作用。
- **关键问题**：今天环境处在"进攻/震荡/防守"哪一档？靠什么量化信号判定？环境正在往哪个方向过渡？
- **现有材料**：米氏手册(量能台阶3.5万亿主升/3万亿退潮)、akshare 每日量能/涨跌停/连板梯队。
- **缺口**：系统的"情绪周期→环境"映射理论（见板块2）。

### 板块2 · 周期（情绪周期，本系统的灵魂）
- **要吃透**：情绪周期五阶段——**启动(冰点反弹)→发酵(普涨扩散)→高潮(百股涨停/最高标见顶)→退潮(炸板+跌停潮)→冰点(缩量地量)**——的识别信号与**过渡拐点**；周期如何"从一个题材切到下一个"；季节/月度/周内多级周期嵌套。
- **关键问题**：现在是周期第几阶段？下一个拐点的信号是什么？周期正在从哪切到哪（题材/风偏）？
- **现有材料**：米氏"夏季→秋季周期切换""涨价暗线→IPO暗线"。
- **★缺口(要你找)**：**经典情绪周期理论**——如"情绪周期波浪/涅槃论"、赵老哥/北京炒家/欢乐海岸/乔帮主一类顶级游资的**情绪周期语录与复盘**；这是把"周期"讲透的核心，我现在只有米氏一家之言。

### 板块3 · 题材（主线诞生/扩散/轮动）
- **要吃透**：主线题材如何诞生（消息/业绩/产业趋势/资金选择）；如何扩散（龙头→分支→边缘）；题材间的**轮动、切换、嫁接、穿越**；主/次/险三分类；一日游 vs 波段 vs 主升 的判别。
- **关键问题**：今天真正的主线是谁？它在生命周期哪一步？有没有新题材在接棒？
- **现有材料**：米氏题材树、akshare 涨停行业扎堆。
- **缺口**：题材发酵路径**案例库**（历史上主线从0到高潮到消亡的完整案例，用于对照）。

### 板块4 · 情绪（个股/盘面微观情绪）
- **要吃透**：连板梯队健康度、封板质量（封成比/首封时间/炸板）、分歧转一致/一致转分歧、龙头卡位与断板、接力 vs 抱团 vs 套利。
- **关键问题**：今天盘面情绪温度几度？最高标健不健康？梯队会延续还是断层？
- **现有材料**：米氏 + 竞价封板训练（首封时间/封单/连板→次日封板率）。
- **缺口**：**龙头战法/接力战法**系统教材（如何卡位一进二、断板低吸）。

### 板块5 · ★集合竞价（短线命门之一）
- **要吃透**：竞价定强度（竞价额/量比排名）、高开/低开博弈、竞价抢筹 vs 砸盘、一字板竞价撬板、竞价与开盘后承接的关系、竞价预判当日/次日封板。
- **关键问题**：今天竞价谁定了强度？竞价语言在说什么（资金进/出/试盘）？
- **现有材料**：竞价封板训练（竞价一字47%/黄金组合70-75%，盘后首封时间口径）。
- **★缺口(要你找)**：①**竞价深度解读教材**——竞价金额/量比/未匹配量/竞价异动 的含义与实战；②**真实集合竞价数据源**（9:15-9:25逐笔或竞价快照），免费源只能近似，若你有付费源(如同花顺/通达信L2/聚宽)会质变。

### 板块6 · ★龙虎榜/席位（短线命门之二）
- **要吃透**：资金五性质（机构/北向/量化/游资/散户）；顶级游资风格与偏好；席位跟踪价值（上榜后胜率）；买卖力度/五档均匀度/家人占比；席位联动识别（同一批打造）；隔日兑现规律。
- **关键问题**：今天谁在主导核心票？是量化套利、游资造龙、还是机构趋势？该不该跟？
- **现有材料**：米氏席位表 + 席位胜率库(近三月上榜后胜率) + akshare 席位明细。
- **★缺口(要你找)**：**顶级游资打法案例库**（章盟主/赵老哥/炒股养家/量化席位 的实战复盘与手法拆解），把"席位背后的人怎么想"讲透。

### 板块7 · ★★四层的关系 / 过渡 / 转换（最高价值，你反复强调的核心）
- **要吃透**：**环境定周期空间 → 周期定题材持续性 → 题材承载情绪 → 情绪反馈环境**的闭环；每一层如何影响上下层；**转换拐点**如何提前识别（如：环境退潮→周期见顶→主线瓦解→情绪冰点，四者的时滞与先后）。
- **关键问题**：四层现在是否共振（同向）还是背离（分化预警）？哪一层先动、哪一层滞后？拐点信号出现没有？
- **现有材料**：米氏自上而下框架（指数→题材→个股）。
- **缺口**：这层主要靠**每日实盘复盘 + 案例积累**自我锤炼，暂不缺外部材料，但板块2/5/6的材料补齐后，这层会大幅加深。
