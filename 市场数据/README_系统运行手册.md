## 四、选股逻辑（层层过滤，别跳闸门）
1. **环境闸门**：先判 A主升/B震荡/C退潮(评分卡)。★退潮/弱环境里所有历史组合打折甚至失效——环境凌驾于模式。
2. **公告闸门**：候选查公告面，利空(减持/监管/异动/风险提示)一票否决。
3. **龙头分**：身位30+封单质量25+资金20+题材地位15+席位加成(胜率库加权)。
4. **竞价**：竞价一字47%>秒板28%；封成比>3%达40%；黄金组合(竞价一字+封单强+0炸板+散票)70-75%——但只是常态基准。
5. **席位**：主战场资金性质(量化套利/游资造龙/机构趋势)+胜率档S/A/C(西大街C慎跟)。

## 九、复盘总结闭环（2026-07-07 新增）
- **结构**：每块 T 日笔记在 5 维度下方新增「六、复盘总结（T+1 回顾）」区块，含 **（1）复盘总结** 与 **（2）验证** 两部分。
- **闭环机制**：T 日只记录（区块为 `⏳ 待 T+1 复盘` 占位）；**T+1 当日复盘时回填** T 日的复盘总结区块——对照 T 日推演/预判回顾实际演化（复盘总结），并逐项验证 T 日观察/信号是否成立（验证，标 ✓/✗/△）。形成「记录 → 次日验证」闭环，每块笔记自含「我当时怎么看 + 后来怎么走」。
- **回填方式**：用 bash python 读 `日记.md` 全文 → 替换该日区块占位 → 整体写回（勿用 Edit/Write 直接改中文长行，防截断）。`复盘闭环.py` 可扫描哪些块待复盘。
- **页面**：`生成学习日记HTML.py` 将复盘总结区块渲染为独立虚线框（已回填=青绿实框，待复盘=灰框+⏳ 徽标）；页眉显示「复盘闭环状态：已回填 X / 待复盘 Y」。
- **自动化建议**：`mikai-morning-auction`(9:40 晨间)天然是 T+1 复盘钩子，可在其 prompt 加「回填昨日复盘总结区块」一步，使闭环自动跑。
