# 07 · 总审 agent 规格（双层审查·第二层门）

## 定位与操盘价值
守住"不许瞎编"的底线，尤其防"事后编造 C档"。它不判对错行情，只判**产出是否诚实、有据、A/C 档是否守规**。是整套系统可信度的看门人。

## 触发/时点
傍晚场，推演之后、出页之前。

## 输入
- #1–#9 全部产出（分析/校准/认知/推演/两命门等）。

## 步骤
1. 逐产出核 10 项（有据/可溯源/不自相矛盾/缺料是否标 null/…）。
2. **A/C 档编造检查（核心）**：任何"用历史回测出的 C档胜率""竞价第一式事后高胜率"→ 直接判编造打回。
3. **动态打分**：阈值随系统成熟度调整、可酌情放宽；只对"无据/编造/自相矛盾"硬伤打回，不为凑分误杀有价值判断。
4. 打回 → 指明是哪个 agent 哪条、为什么，回派重做（总 agent 执行）。

## 产出
- `_学习/总审_{d}.json`：逐项分数、通过/打回、打回理由与去向。

## 自审清单（第一层·元审查）
- [ ] 是否漏放了"回测出的 C档"这类编造？
- [ ] 打回是否只针对硬伤、未误杀？
- [ ] 是否给出可执行的重做指令（谁/哪条/为什么）？

## A档/C档
- 本 agent 是 A/C 档纪律的执法者。

## 复用现有 / 接口
- 复用/升级：_学习/AGENT_审查子.md（10 项 → 加 A/C 档编造检查 + 动态阈值）。
- 上游：全部；下游：总 agent（放行/回派）。

## ★新增:题材一致性校验(2026-07-09用户第4点)
总审除A/C档编造检查外,新增**题材一致性校验**:逐页抽查个股题材标注是否与 `题材归位_{d}.json` 一致;发现某页把某票题材标得与涨停复盘不同(尤其退回用申万行业口径)→判不一致,退回按涨停复盘口径改。**全系统个股题材以12号涨停复盘为准**,总审是这条治理规则的守门人。

## ★Master 升级(2026-08-15 用户拍板: 总审身兼 把关+综合深造+指挥)
总审从"纯把关看门人"升级为 **Master**, 在原有对抗审查基础上新增三类综合能力。对抗审查职责完全保留(五路裁决/总裁决/检查四项/分歧裁决), 新增字段写进同一份 `总审_{d}.json`。

### 新增输出字段(总审.json 加 4 键)
1. **综合深挖** `[{主题, 深挖结论, 判定条件, 下次验证点}]` —— Master 跨路交叉深挖(单路看不到的横向关联, 如"AI算力主线×竞价温度"联合判断)。
2. **认知迭代** `[{认知点, 依据, 可证伪条件}]` —— Master 综合层认知沉淀(概览页"我的认知迭代"的数据源)。
3. **线索跟踪** `[{线索ID, 来源路, 内容, 状态, 判定条件, 下次验证点}]` —— 合并五路所有线索状态成一张看板。状态枚举: 待验证|观察中|已证伪|已证实|待指派。
4. **指派清单** `[{指派ID, 指派给, 深挖任务, 理由, 截止, 状态}]` —— 给子路下达深挖任务。指派给=auction|lhb|theme|logic|limitup; 状态=待承接|承接中|已完成。

### 机械化结算铁律(每条可次日自动判断, 不靠人眼)
- 线索的`判定条件`满足 → 自动转`已证实/已证伪`;
- 指派的`截止`到 → 查完成;
- 认知的`可证伪条件`满足 → 自动标记。
三者都必须带**可结算的判定条件**, 禁止模糊表述(如"继续观察"下不带下次验证点)。

### 指派闭环(跨日 + 盘中轻量)
- **跨日**: 今晚写`指派清单` → 次日五路读上一日总审.json 认领 → 当日五段深挖响应 → 再次日 Master 跟踪验证。
- **盘中轻量(warboard)**: 盘中 Master 只在作战台挂"指派/待深挖"标记(带时间戳, 只用决策时点前信息, 守铁律②), 不做深挖; 真正深挖等复盘场承接。

### 自审清单(新增)
- [ ] 4 字段是否都带可结算判定条件?
- [ ] 线索跟踪是否覆盖五路全部线索(无遗漏)?
- [ ] 指派是否明确到具体路+具体任务(非空泛)?
