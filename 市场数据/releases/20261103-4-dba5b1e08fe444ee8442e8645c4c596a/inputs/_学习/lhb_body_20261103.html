今日最重要的新发现：冰点层桶序反转，0-5% 从最优变最差。全年混合温度下 0-5% 是全库最好的桶（n=1300 / 48.2% / +0.54%，score 22.4），但本路按市场温度分层自算（窗口 20260615~20261030、23 个冰点日、2417 笔、执1 = T+1 开→收）后，冰点×涨停 的 0-5% 变成最差桶：n=76 / 40.8% / −0.19%，而 5-10%（n=75 / 46.7% / +0.49%）与 10-20%（n=92 / 48.9% / +0.50%）才是正的，>20% 为负（n=46 / 34.8% / −0.32%）。解释：冰点日的小占比买盘是「弱共识下的零星接货」，不是低拥挤；只有 5-20% 的「有力度但不过分」在冰点有效。今日两只候选恰好落在 0-5% 与 >20% 两个负桶，正桶空档——这是 0 荐票的第一层原因。
