# 07 · 总审 agent 规格（双层审查·第二层门）

## 定位与操盘价值
守住"不许瞎编"的底线，尤其防"事后编造 C档"。它不判对错行情，只判**产出是否诚实、有据、A/C 档是否守规**。是整套系统可信度的看门人。

## 触发/时点
傍晚场，推演之后、出页之前。

## 输入
- #1–#9 全部产出（分析/校准/认知/推演/两命门等）。

## 步骤
1. 逐产出核 10 项（有据/可溯源/不自相矛盾/缺料是否标 null/…）。
2. **A/C 档编造检查（核心）**：任何"用历史回测出的 C档胜率""竞价第一式事后高胜率"→ 直接判编造打回。
3. **动态打分**：阈值随系统成熟度调整、可酌情放宽；只对"无据/编造/自相矛盾"硬伤打回，不为凑分误杀有价值判断。
4. 打回 → 指明是哪个 agent 哪条、为什么，回派重做（总 agent 执行）。

## 产出
- `_学习/总审_{d}.json`：逐项分数、通过/打回、打回理由与去向。

## 自审清单（第一层·元审查）
- [ ] 是否漏放了"回测出的 C档"这类编造？
- [ ] 打回是否只针对硬伤、未误杀？
- [ ] 是否给出可执行的重做指令（谁/哪条/为什么）？

## A档/C档
- 本 agent 是 A/C 档纪律的执法者。

## 复用现有 / 接口
- 复用/升级：_学习/AGENT_审查子.md（10 项 → 加 A/C 档编造检查 + 动态阈值）。
- 上游：全部；下游：总 agent（放行/回派）。

## ★新增:题材一致性校验(2026-07-09用户第4点)
总审除A/C档编造检查外,新增**题材一致性校验**:逐页抽查个股题材标注是否与 `题材归位_{d}.json` 一致;发现某页把某票题材标得与涨停复盘不同(尤其退回用申万行业口径)→判不一致,退回按涨停复盘口径改。**全系统个股题材以12号涨停复盘为准**,总审是这条治理规则的守门人。
