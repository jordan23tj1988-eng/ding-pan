# 04 · 提炼优化 agent 规格

## 定位与操盘价值
进化引擎——决定我最终能否脱离米开、长出自己的体系。吃累积在案的真实反馈，给规则打脸降权/加权；这是把"经验"变成"越来越准的判断力"的地方。

## 触发/时点
傍晚场，校准之后、认知之前（先进化规则，认知才用升级后的知识）。

## 输入
- `_学习/在案_校准.jsonl`（全部历史结算）
- 现有知识底座：`_评分卡与校准规则.md`、`_竞价训练结果.json`、`_龙虎榜量化.json`

## 步骤
1. **持续标方向**：每条规则统计近期验证/打脸计数，标当前偏向（未到阈值不动权重，先挂账）。
2. **阈值触发大提炼**：某规则样本≥阈值 → 正式调权重（打脸降、验证升）或改写/淘汰。
3. **时效衰减/近因加权**：越近的反馈权重越高；风偏类规则设半衰期(约2周)，过期 edge 主动降权。
4. **A/C 档分治**：只对 **A档规则量化调权**；**C档只累积实盘观察**，绝不用历史"回测"出 C档胜率（防编造）。
5. **脱离米开留痕**：某条米开规则被真实数据反复证伪 → 记入 `_学习/_偏离米开.md`（哪条、证据、替代规则）。

## 产出
- 升级后的 `_评分卡与校准规则.md`（版本化）
- `_学习/_规则权重.json`（每条规则：权重/样本数/近因分/A-C档/方向）
- `_学习/_偏离米开.md`（自有体系生长记录）

## 自审清单（第一层）
- [ ] 是否只动"已在案真实反馈"，无凭空造规则？
- [ ] 是否严守"C档不量化回测"？
- [ ] 样本不足的规则是否只标方向、未硬改？
- [ ] 时效衰减是否生效（老 edge 未被当真理）？

## A档/C档
- 本 agent 的操作对象即 A/C 分治的执行者，是全系统防编造的关键闸。

## 复用现有 / 接口
- 复用/升级：_评分卡与校准规则.md、竞价训练.py 结果、席位库。
- 上游：校准在案；下游：认知（提供升级知识）。
