# 盯盘台页面架构 v2 · 自审与重梳理（2026-07-09）

组织逻辑（骨架）：**四层框架 环境→周期→题材→情绪 + 三命门(竞价/席位/题材) + 产业逻辑 + 涨停复盘(题材真源+质量) → 五路荐票 → 总agent → 明日观察点**。北极星=Claude每日判断+认知迭代自我进化。

## 一、自审：当前4个结构毛病
1. **index 过载**：现在同时挂了 题材归位对照(6有)+环境strip+四层gate+观察点+看牌+拐点+迭代——题材内容和 limitup/theme 三处重复，首页太杂。首页应只做「总判断 + 明日看牌」。
2. **环境层无家**：环境(量能/涨跌停/炸板率)是四层最顶层，现在只作 index 一个 strip，没展开。它该和周期合并成一页(环境→周期→情绪=市场温度)。
3. **题材三处重复**：题材归属出现在 index(callout) + limitup(全表) + theme(判定)。按新治理规则，题材唯一真源=涨停复盘(limitup)，其他页不该重造。
4. **情绪层定位模糊 / 认知迭代过长**：情绪档在 index、情绪指标(连板梯队/炸板)在 cycle，割裂；且每页认知迭代全量堆在页里，首页尤其长。

## 二、重梳理：每页只干一件事（对齐四层/命门）

### ① index 概览 —— 「我的总判断 + 明日看牌」（情绪层出口/总agent）
- stance：情绪档 · 周期阶段 · 攻防仓位档（一屏定调）
- ★明日核心观察点表：五路荐票综合结果，每只 = 标的|身位逻辑|明日触发|**荐票来源(几路荐)**|四维共振数|**质量分**|类型
- 四维·操盘手看牌：竞价/席位/题材/产业逻辑(+涨停复盘质量) 各一张卡，一句话判断+温度读数，点进各页
- 拐点预警（命门反推背离时才显著）
- 认知迭代：**只显最新1条**，链接 history
- ★移走：环境明细→cycle；题材6有对照→theme/limitup（首页瘦身）

### ② limitup 涨停复盘 —— 「题材地基(唯一真源)+质量训练+荐票」（题材层地基/12号）
- 全场速览（涨停数/主流聚类6有/来源档A-B-C/质量分≥70数）
- ★质量 Top5 荐票卡 → 总agent（第5路）
- 全量三层题材归位表（大方向→环节→个股 + 封板四维 + 质量分 + 预测T1/T2）＝**全系统题材唯一真源**
- 题材核对说明（跨界识别清单 + A/B/C）
- 主线 vs 散乱结构
- 训练：涨停质量训练库（`details.chain` 折叠，不撑长）

### ③ cycle 周期情绪 —— 「环境→周期→情绪：市场温度与攻防档」（环境层+周期层）
- ★环境 strip（成交额/量能台阶/涨停·跌停/炸板率/最高板）＝**从 index 下沉到这**
- 情绪五阶段定位（冰点/启动/主升/混沌/退潮）
- 连板梯队断层可视化（ladder）
- 攻防仓位总开关（量能台阶→仓位映射：主升8-10成/混沌4-5成/退潮0-2成）
- 认知迭代

### ④ theme 主线题材 —— 「方向：主流还是分支、能走多久」（题材命门/形）
- 三级判定（★聚类口径：主流/大分支/分支，行业口径作对照）+ 题材命门温度
- 主流生命周期（主升浪/补涨/衰竭，断板≠结束）
- 核心标的与龙头识别
- 认知迭代
- ★题材归属**链接 limitup 三层表，不重复全表**（只做判定与龙头）

### ⑤ logic 产业逻辑 —— 「逻辑硬不硬、链条谁卡位」（题材命门/神·11号）
- 今日主线链条纵深（全链条环节位置/涨到位标尺/未涨双口径/高低切地图）
- 前置预期雷达（消息|激活题材|潜在受益|时间点|状态）
- 挖掘荐票追踪（第四路荐票，逐日结算只加不删）
- 链条深度地图库（每产业 `details.chain` 折叠）
- 认知迭代

### ⑥ lhb 龙虎榜 —— 「钱在买什么」（席位命门）
- S/A 席位今日买了什么 + 综合量化判断
- 席位胜率追踪 Δ（1/2/3日全口径）
- 资金信号胜率追踪 Δ
- 认知迭代

### ⑦ auction 竞价 —— 「点没点火、次日兑现」（竞价命门）
- 竞价选股池·当日（首封≤9:31，封单比/T+1封板概率）
- 昨日池今晨初读 / 傍晚终结算（竞价池初读.py）
- 竞价信号胜率追踪 Δ
- 认知迭代

### ⑧ history 历史 —— 每日冻结存档列表（不变）

## 三、跨页原则（去重与一致）
1. **一页一职责、一四层/命门映射**，不越界重复。
2. **题材唯一真源=limitup(涨停复盘)**；theme/logic/index 引用不重造三层表。
3. **认知迭代**每页只加不删；**index 只显最新1条**，全量在各页/history。
4. **荐票流**：index 观察点=五路综合(标来源+质量分)；各源页只展示本路荐票（竞价/席位/题材/产业逻辑/涨停复盘）。
5. **折叠收纳**（`details.chain`）：训练库、链条地图库等长内容折叠，保持页面精简。

## 四、相对现状的具体改动清单
- index：删「题材归位6有对照」段、删「环境strip」段；观察点表每只加「荐票来源」列；认知迭代收成最新1条。
- cycle：顶部新增「环境 strip」（承接 index 下沉）；补「攻防仓位总开关」段。
- theme：删三层全表，改为「判定+生命周期+龙头」并链接 limitup。
- limitup / logic / lhb / auction：职责已对齐，维持（微调标题层级）。
