# 02 · 分析 agent 规格

## 定位与操盘价值
把原始池翻译成**米开语言的盘面事实**。不是罗列"今天57家涨停"，而是每个数字都落到"这告诉操盘手什么"。产出是认知 agent 的事实底座。

## 触发/时点
傍晚场，取数之后。

## 输入
- `{d}/` 原始池 + summary.json；`_席位胜率库.json`、`_龙虎榜量化.json`(供交叉)。

## 步骤（按米开 V2 框架算）
1. **量能台阶**：两市成交额 → 查换算表(可支撑主线数 / 连板高度上限 / 龙头涨幅上限)。
2. **连板梯队**：连板高度分布、晋级率、封板率、炸板率、跌停家数、连冰计数、黄白线。
   - ★先行指标(2026-07-11 P0落地)：跑 `python3 R/情绪先行指标.py {d}` → `_学习/_情绪先行指标.json`(THS口径250日已回填)。1进2率/2进3率/高度晋级率=周期拐点最灵敏先行信号(实证:07-06涨停64但1进2仅3.8%=冰点级,当日即可撑"临界偏退潮";07-10高度晋级0%=高度崩塌量化)。昨日涨停溢价(执行口径,bars_cache已回填249日真值+spot每日累积);大面率/核按钮率同json。cycle页量能台阶辅读必须引用这三条,拿不到标null。
   - ★三条A档择时窗(冰点触发器回测.py 2026-07-11定稿,脚本每晚自动判并写入json'触发器'字段,必须原样引用):①冰点进攻窗=温度<25(次日接力y1均+0.30%/胜率60%,n=15日/12独立段,基准-0.21%/45%)——冰点敢喊进攻;②过热禁追窗=温度≥85(0/6全负均-1.86%);③洗出反弹窗=昨停溢价连负3日(次日+0.46%/65%,n=34,只反弹不反转)。★注意:复合"≥2转机分量"硬条件已被回测证伪(250日仅1次触发且为负),分量只作叙事;"溢价连负3日=退潮确认"旧说法已被数据推翻(实为反弹窗)。全部小样本+单牛市周期(2025-07~2026-07),给环境判断不给指令。
3. **龙头**：核心标的身位/主动性/带动性/抗跌性/辨识度打分(现有龙头分)。
4. **题材三要素**：容量 + 预期 + 消息刺激频率 → 题材树 + 主次/避险/过渡归类。
5. **异动红线标记**：对每个核心标的算 10天涨幅/30天涨幅，贴近 100%/200% 打红旗。
6. 每条事实附一句"操盘含义"。

## 产出
- `{d}/analysis.json`：量能台阶结论、梯队/情绪指标、龙头分表、题材树、异动红旗名单，每项带 A/C 档标签 + 操盘含义。

## 自审清单（第一层）
- [ ] 每个数字是否可从原始池复算、可溯源？
- [ ] 是否每条都写了"操盘含义"，无干罗列？
- [ ] 量能台阶/异动红线是否按 V2 阈值？
- [ ] 拿不到的项是否标 null 而非估算？

## A档/C档
- 量能台阶、连板/封板/炸板率、异动红线、龙头客观分项 = **A档**。
- "当日盘口护盘意图""真杀假杀"等主观项 = **C档**，标注并克制断言。

## 复用现有 / 接口
- 复用：分析引擎.py、公告跟踪.py。
- 上游：取数；下游：认知（事实底座）、推演、校准。
