# AGENTS.md — 工作区协作纪律（Hermes 与 Claude Code 共写此目录）

> 本目录 `D:\股票数据\市场数据` 是 A股情绪复盘系统**生产工作区**，由 **Hermes**（总指挥）与 **Claude Code**（协作编码）共同维护。文件是共用的，你的改动必须让对方**认识**——以下纪律双方通用，开工前必读。

## 0. 一句话铁律

**动手前让对方知道你在改什么，改完让对方验证得了你改的对不对。** 禁止静默覆盖、禁止改完不留痕。

## 1. 开工三查（每次开始干活前）

```bash
python _协作/检查改动.py check     # ①自上次以来哪些文件被改过(对方动过=先看变更总账/改动声明理解, 再动手)
python _协作/改动声明.py list      # ②有没有"进行中"声明(对方正在改的文件=不要碰, 先沟通)
cat _变更总账.md | tail -30        # ③最近登记了什么(生产脚本改动必须登记)
```

## 2. 改动流程（每笔改动）

1. **声明**：`python _协作/改动声明.py declare "<你的名字>" "文件1,文件2" --purpose "改什么" --impact "影响面"`
2. **动手**：只改你声明的文件；**只读镜像不碰**（`D:\黄金对照版717\`、archive 历史存档、"哈药5板"类历史日块文本）
3. **验证**：改完必跑——
   - 动了哨兵/渲染/生成 → `python limitup数据核对.py <日期>` 必须 PASS（FAIL 不许交接）
   - 动了脚本 → `回归_链路.py`（如有）
   - 新 class/组件 → C32 设计令牌收编
4. **登记**：`_变更总账.md` 追加一行（日期/改动/根因/验证）
5. **收尾**：`python _协作/改动声明.py done "<你的名字>" --verify "哨兵rc=0 PASS"` + `python _协作/检查改动.py update`

## 3. 数字引用铁律（当日事实卡）

写任何文本（judgment 一句话/bodies/来源/组件文案）引用 涨停数/温度/最高板/票名+板数，**一律从当日权威真源取**：
- `_学习/_市场温度表.json`（涨停数/温度/最高板）
- `_学习/_ths_zt_pool.json`（high_days"N天M板"，连续板=天==板）
禁止从历史日块/记忆抄数字（7/16"哈药5板"是历史存档≠当日事实）。哨兵维度8 会机器拦截，写错即 FAIL。

## 4. 历史与只读边界（改了也白改/会坏事）

| 目录/文件 | 规则 |
|---|---|
| `D:\黄金对照版717\` | **只读基准，永不动** |
| 历史日块（7/16 及更早的 bodies/页面） | 存档快照，**永不动**（"哈药5板全场最高"是当时正确） |
| `_学习\题材归位_20260811.json` 等当日真源 | 可改但要登记+跑哨兵 |
| `复盘\盯盘台\limitup.html` | 由生成器产出，**手改会被重渲染冲掉**——改 bodies 再重渲染 |
| 你自己新建的分析目录 | ✅ 随便写，不影响生产 |

## 5. 版本/口径一致性

- 页面组件规范/设计令牌 → `_盯盘台组件规范.md` + `_架构/设计令牌.json`（新 class 先收编）
- 契约（json 结构）改动 → 先填影响面分析单（`_架构/影响面分析单.md`），再动
- 升级版本号 → `cockpit_versions.json` + 分层模型 bump
