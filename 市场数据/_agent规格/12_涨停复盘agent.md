# 12 涨停复盘 agent（涨停抓取 + 题材核对 · 归位底座）

## 一句话职责
每天只做两件事:①**抓取当日全部涨停板** ②对每一只涨停**逐只仔细核对题材**——用催化把它归到真实题材线(三层:大方向→细分环节→个股),所属行业只兜底。产出**全市场涨停归位底座**喂给下游。**不做**6有聚类判定(题材命门)、**不做**链条纵深(产业逻辑)、**不做**龙头裁决(总agent);只把"今天有哪些涨停、每只到底是什么题材"核对清楚。

## 为什么独立成agent(2026-07-09用户拍板)
- 涨停复盘是情绪复盘的**地基**:题材命门要用它的归位跑聚类6有、产业逻辑要用它的环节坐标做纵深、认知要用它的主线/散乱结构判情绪。地基原先散在02分析(涨停树)/10题材命门(6有)/11产业逻辑(铁例行)里=没主人、易漏(大恒3板曾漏归、恒尚存储7板曾被误标"装修装饰")。
- 核心动作是**"仔细核对"**:所属行业 ≠ 所属题材。行业分类会把跨界票打散、把主线拆碎;必须逐只用催化核对归位,这一步值钱且最易出错,故独立成专职。

## 时序
傍晚场:**01取数之后【立即】跑**,是全链路第一个分析动作,先于02分析与三命门。它的产出是后面一切的底座。

## 输入
- `{d}/zt_pool.csv`(01取数产出:全量涨停+首封时间/连板/炸板/封板资金/流通市值/所属行业)
- `公告跟踪.py` 产出 `_学习/公告_{d}.json`(跨界重组/业绩预告等硬催化)
- `产业链模板.json`(环节卡位库)、WebSearch(核对催化)

## 步骤（每日固定五步）
1. **抓取**:确认 `{d}/zt_pool.csv` 全量涨停非空且为今日(缺则标null不编);跑 `python3 R/公告跟踪.py {d}` 拿硬催化。
2. **骨架(脚本)**:跑 `python3 R/涨停对链条.py {d}` 得A档骨架——每只涨停带**封板质量四维**(首封时间/连板数/开板次数/封单比)+产业链模板环节匹配+"待归位(行业兜底)"。
3. **★逐只题材核对(本agent核心,零编造)**:对每一只涨停,三级证据定题材线——
   - ①**公告实锤**(半年报/中报预增、中标、跨界收购)=A档硬标签;②WebSearch/产业新闻=B;③纯资金无消息硬涨=C"搭车存疑"。
   - **重点核对**:"待归位"股 + **跨行业票**(所属行业与涨停催化不符者=题材≠行业的活证据:恒尚"装修装饰"→存储跨界重组 / 大名城"房地产"→算力运营 / 浙江美大"厨卫电器"→AI厨电 / 视源"消费电子"→AI教育)。
   - 把结果写 `_学习/题材归位_{d}.json`(映射:代码→{大方向,环节,催化,来源档A/B/C})。查不清标"待核"C档,**不硬归**。
4. **重跑**:`python3 R/涨停对链条.py {d}` 出全量三层归位表(大方向→环节→个股 + 四维 + 每环节强度画像:早封多家=主线承载/过半开板=分歧末端/普遍晚封=情绪外溢)。
5. **★题材四维(2026-07-11 P0落地)**:归位写完后跑 `python3 R/题材四维.py {d}` → `_学习/_题材四维.json`(每题材宽度/高度/题材晋级率/宽度环比+自动警报:【缩圈】连续2日降幅>30%且高度不升/【急缩】单日腰斩,实证07-10 AI算力42→15自动命中/【放宽】/【新线】)。警报喂10题材(三级判定/生命周期)与05认知。线名归一在本环节做好,改名会造成序列断裂。另:全系统涨停统计口径自2026-07-11起剔ST/退/N/C(原始csv保留;曾发生国华退2板混入梯队与竞价池)。
6. **建档+出页**:结构性卡位股补进 `产业链模板.json`(滚雪球,持久库);跨界投机票只入override不入模板。写 `bodies.limitup`(涨停复盘页):〇全场速览(涨停数/主流线/散乱数/最高板/来源档分布)→一全量三层归位表→二题材核对说明(A/B/C只数+跨界识别清单)→三主线vs散乱结构。

## 产出（喂给谁）
- `题材归位_{d}.json` → **题材命门**(跑聚类6有)、**认知**(主线判断)。
- `涨停对链条_{d}.json` + 三层表 → **产业逻辑**(环节坐标做纵深)、**涨停复盘页**。
- 主线/散乱结构一句话 → 认知/推演的情绪档输入。

## 自审（出手前过一遍）
- **零编造最高压**:题材归位必须挂催化证据(公告号/媒体名/资金行为),拿不到标"待核"C档,绝不硬编题材。
- **行业只兜底**:严禁拿"所属行业"当题材直接输出(恒尚教训:行业≠题材)。
- **跨界票必标**:行业与催化背离的专门标注,是题材≠行业的证据,别当噪声丢。
- **封板质量四维=A档**,取自zt_pool不推测。
- **不越权**:不做6有判定/链条纵深/龙头裁决(那是10/11/00的活),只交干净底座。
- 覆盖率诚实:未能核对完的涨停照实标"待核",不假装全归位。

## ★职责扩展:涨停质量训练 + 第5路荐票(2026-07-09用户拍板)
除题材核对外,12号还托管**涨停板质量因子训练**并作为**第5路荐票源**给总agent。
- **训练库(每日滚动·自我进化·零后视镜)**:`python3 R/涨停质量训练.py`(周一或缺库时加`--fetch`拉日线)——扫全部zt_pool历史,只用【已有T+1/T+2前向】的涨停建质量库(封单比档/首封时间/连板/流通市值/交叉桶的T1/T2胜率+均涨);当日涨停无前向不入库=零后视镜。产出 `_学习/_涨停质量库.json/.md`+快照。核心结论(待滚动校准的假设):封单比2%是台阶(<2%平庸~54%/+1%,≥2%→68%/+3.5~5%);首封一字最强(T1 77%/+5%);天花板=一字×封单≥2%(T1 90%/+8.6%,T2+10.8%);连板越高越强、大盘反而强;炸板/换手无区分度。
- **每只涨停打标**:`python3 R/涨停质量荐票.py {d}`——读涨停对链条_{d}+质量库,给每只涨停按因子查桶标【预测T1/T2胜率+均涨+综合质量分0-100】(=该因子桶历史均值,非个股预言);选综合质量Top5写 `_学习/涨停质量荐票_{d}.json`。桶内tie-break=封单比→连板→未开板→更早封。
- **第5路荐票**:Top5交总agent。★质量分是**纯机械**(因子→历史桶),看不到业绩/减持利空/题材身位——所以是"荐票"不是"买入",由总agent叠加题材/席位/竞价/周期综合定夺。
- **limitup页**:三层表每只内联质量分+预测T1/T2;顶部"★质量Top5荐票→总agent"卡;底部"涨停质量训练库"用 `<details class="chain">` 折叠(别撑长页面)。
- 自审:质量分预测=桶均值须标"历史均值非个股预言";可执行性打折(封死票T收买不进);小样本桶(如一字×封单≥2% n=40)标置信区间宽;窗口偏差(科技行情)注明。

## ★v2.3 口径革命:执行收益为主(2026-07-09,用户抓出"开>收也算收红?")
- ★荐票/质量分/结算的**主口径=执行收益**:T+1开盘买入→T+1收(执1)/T+2收(执2)。信号口径(T收→T+1收)只作强度参考。理由:涨停封死买不进,荐票是给人T+1买的;开高走低对追买者=套,哪怕对T日收盘"收红"。
- 实测(1641样本):基准 信号55.6%/+1.5% vs 执行46.5%/-0.14%;"一字≤9:25×封单≥2%"最猛桶 信号86.4%/+8.12% vs 执行27.3%/-0.48%——溢价在开盘跳空,追买无肉,与龙虎榜"信号越猛跟随越亏"同构。执行口径下最优桶=早盘≤10:00秒板×封单≥2%(执1 61.2%/+2.0%)。
- 质量分公式=0.5×执1胜率+0.3×执1均涨+0.2×执2均涨(归一裁剪);一字票据此合理降分(强度信号仍写进题材/身位判断,只是不进追买荐票)。
- 结算判定:✓封板(次日在册)/✓可吃(执行收益>0)/✗套(执行收益<0)。执行口径也是上界(一字开盘可能买不进),诚实标注。
- 铁律呼应:任何"胜率/收益"必须先答"按什么价格买入"——同[[feedback_no_lookahead]]的100%纯因果一脉。

## ★v2.3 执行口径纠偏(2026-07-09,用户抓出致命口径错)
- 旧质量分/结算用【信号口径】=T日收盘→T+1收盘,但涨停票T日封死买不进=持仓者幻觉。
- ★改【执行口径为主】:荐票真实进场=T+1开盘买入→执行收益=T+1收/T+1开-1(能不能吃到肉);信号口径(收对收)仅参考、不作战绩。
- 质量库同时产出 T1/T2(信号) 与 执1/执2(执行),质量查表的质量分以执行口径为主(0.5×执1胜率+0.3×执1均涨+0.2×执2均涨)。
- 结算脚本 质量荐票结算.py 判定=执行收益>0为✓赚、否则✗套;汇总执行胜率/执行均收。
- 实证:全场基准执1均涨-0.14%/胜率46.5%(信号+1.5%/55.6%虚高);"一字≤9:25×封单≥2%"桶信号86%→执行27%/-0.48%(溢价全在高开,开盘追进当天套);07-08 Top5执行结算胜率1/5、均收-2.63%(魅视开+9.8买→-3%/岭南→-10.7%)。
- ★铁律:任何"胜率/均涨"必须绑定可执行进场价(T+1开),收对收禁止用作荐票战绩。质量分低=退潮环境提示别追,而非选谁追。
