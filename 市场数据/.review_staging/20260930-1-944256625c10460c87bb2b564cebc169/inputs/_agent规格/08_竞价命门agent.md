# 08 · 竞价命门 agent 规格（专家·权重高）

## 定位与操盘价值
操盘手的第一只眼：竞价定"今天能不能上、什么价上"。用米开第一式深读竞价强弱，出次日竞价预判。它是短线最锋利也最"只能实盘"的一块。

## 触发/时点
- 傍晚场：为次日出竞价强弱预判（喂认知/推演）。
- 早盘场 9:30 前：读今日集合竞价，出即时强弱，对照昨晚预判。

## 输入
- 竞价快照 `_学习/竞价快照_{d}.json`；`_竞价训练结果.json`；分析事实。

## 步骤
1. 米开第一式框架：1字数量(≥2定强度)、竞价量能/金额排名、跳空高开幅度、竞价换手(前日成交额 8%-15%)、题材新鲜度。
2. 四条件叠加判安全性：竞价强 + 开盘强 + 盘口强 + 板块联动强。
3. 出"明日盯盘清单"：哪几只、什么竞价特征算强/算弱放弃。
4. **诚实边界**：第一式核心信号(925成交额排名 + 逐笔大单)=C档只能实盘，历史不可复现；历史学习只能训 A档代理(竞价换手/开盘位置/高开幅度→次日封板率)。

## 产出
- `_学习/竞价命门_{d}.json`：竞价强度分层、盯盘清单、次日预判（每条标 A/C 档）。

## 自审清单（第一层）
- [ ] 是否把第一式核心明确标为 C档、不假装可回测？
- [ ] 历史训练是否只用可得的 A档代理？
- [ ] 强弱结论是否有竞价真实数据支撑、拿不到标 null？

## A档/C档
- 竞价换手/开盘位置/高开幅度 = A档代理；925 成交额排名、逐笔大单、"分时是否卡竞品" = C档只能实盘。

## 复用现有 / 接口
- 复用：竞价训练.py、竞价快照.py、竞价验证.py。
- 上游：取数；下游：认知、推演、校准。
## 历史深度学习（延后）：批量吃可得历史竞价 A档代理，建"竞价语言→次日兑现"因果库，深度提炼非浅层统计。

## ★★auction页改版:竞价池发出版冻结+脚本化强制结算(2026-07-11用户拍板,与theme/logic页同构,五路闭环收官)

### 竞价池结算闭环(照质量/席位/题材/逻辑路骨架,战绩不靠嘴)
1. **发出版**:池=零后视镜确定性名单({d}/zt_pool.csv 首封≤09:31;一字=首封≤09:25,秒板=其后),首次结算时自动冻结 `_学习/竞价池发出_{d}.json`,★之后只读冻结版不可覆盖。池是"竞价维度全名单"非精选,整池结算。
2. **次日结算**:傍晚场跑 `python3 R/竞价池结算.py {昨日d}` → T+1执行口径逐票(判定=✓封/✓可吃/✗套),产出 竞价池结算_{d}.json + _竞价池结算.jsonl + _竞价池反思.jsonl + 竞价池结算卡_{d}.html(嵌auction页"昨日池终结算"段,替代agent手算表)。基准=当日全场涨停执行均收(读质量荐票结算json同源)。
3. **★三维归因(A档自动记账)**:按信号(一字/秒板)+按连板(首板/2板+)+按高开档(低开≤0/0~5/≥5)——把"低开有肉高开套"从叙事变成每日数字(07-09首验:高开≥5档-4.02% vs 低开档+2.26%)。喂04提炼。
4. agent在结算卡下只写"结构洞察"card(赢家/输家结构,不重复数字);拿不到bars标null不编(脚本自带sina兜底)。
5. 验证在案:脚本对07-09池复算与agent手算完全一致(封板4/12/胜率6/12/均收-0.17%)。

## ★★v3 竞价评分体系+闸门+全市场留档(2026-07-12用户拍板"②③④都做+竞价角度评分",优化①②③④全落地)
**四件套脚本**(全部A档、零后视镜、口径与竞价池结算.py同构):
1. **竞价评分.py {d}**(傍晚,链路b步):冻结当日发出版→每票【竞价分0-100】=一年分桶库桶值(0.6×执1胜率+0.4×执1均涨映射)按区分度加权;维度=封单比(权0.45)/炸板(0.30)/温度(0.11)/信号x连板(0.07)/连板(0.04)/信号(0.02),权重每晚随库自适应。产 竞价评分_{d}.json(★分数唯一源)+竞价评分卡_{d}.html(嵌auction段一:分+主导因子+明晨三情景+闸门预标)。
2. **竞价闸门.py {昨日d}**(早盘9:25后,晨场固化步骤):昨日评分池×今晨实开→"高开≥5%必弃"闸门→今日可吃名单卡,幂等注入auction「★今晨闸门」段;已封板标⊘追不进。--backtest模式供历史演示。★可吃≠荐票,是执行过滤。
3. **竞价全市场快照.py**(早盘9:26,晨场2b步):全A今开/竞价额/竞价额排名/换手代理→_学习/竞价快照存档/{d}.csv.gz+meta(>09:30标污染;失败标meta不造数)。动机=925排名/竞价换手C档转A档:存满一年即可回测。
4. **竞价池结算.py联动**:结算表加竞价分列;归因新增★评分半区(高分半vs低分半)+★闸门对账(高开<5吃进 vs 全池)→评分和闸门每天被结算打脸或验证,战绩不靠嘴。

**★WF验证在案(零后视镜:每月只用之前样本建库打分)**:IC均值0.12,11个月中10个月IC>0;三分位价差均值+1.14pp(10/11月为正);全期三分位单调:低分-1.04%/25.0% → 中分-0.97%/39.7% → 高分+0.01%/45.9%。结果json=_学习/_竞价评分WF.json,复算脚本=竞价评分WF验证.py。
**诚实边界**:①高分组绝对收益≈0,评分定位=池内排序+环境仪表,非荐票;②闸门内评分区分度减弱(中分+0.75>高分+0.61,评分与闸门信息部分重叠);③202607月IC-0.05(n=89半月样本)=会有失效月;④权重全靠历史桶,风格切换期需靠每晚滚动重建自愈。
**每晚链路(08号三步)**:(a)竞价池结算.py {昨日d} → (b)竞价评分.py {d} → (c)竞价池分桶回填.py(4秒滚动更新库)。晨场:快线→全市场快照→初读→闸门。
