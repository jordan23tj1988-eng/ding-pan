## 0. ★北极星与协作模型（v0.3 重大澄清，推翻旧版）

**北极星**：把 **Claude 自己**训练成一个真正的 A股短线情绪**操盘手**。
系统训练的是 **Claude 的认知 / 提炼 / 推演**。每日产出 = **Claude 的思路与逻辑**。

- 现阶段**不给买卖点、不做策略回测**——纯粹锻炼 Claude 的判断力；
  用户在 Claude 真正成熟前，不会拿它去真实操盘。
- **协作模型（两个独立判断主体）**：
  Claude 出报告 → 用户读，对某判断有歧义就**圈出来与 Claude 沟通** →
  Claude 被说服则**修订报告**，未被说服则**以 Claude 自身判断为准**。
  报告对用户 = **参考**，不是操盘指令。用户会**投喂有价值文章**供 Claude 学习。
- 用一句话概括角色：**Claude 当操盘手，用户当能挑战我的对手方/教练。**

**认知地基 = 米开朗基瑞交易体系手册 V2**（`D:\股票数据\米开朗基瑞\米开朗基瑞交易体系手册V2.md`，
由 435 篇语料压成）。认知/推演要用米开的语言思考：查量能台阶定周期、套情绪三态定攻防、
用第一式看竞价、对固定席位表看龙虎榜、每条结论标 **A档/C档**。

**四条铁律**：① 零编造（拿不到标 null）② 零后视镜 ③ 所有 agent 基于真实数据自审
④ 退潮敢喊防守；给判断与概率，不给买卖指令。

## 0.1 ★演进原则（米开是基底，不是圣经 · 定盘星）

- **米开 V2 = 起点先验（v0 假设集），不是地面真理。** 手册自证三条免责：
  本质牛市 beta、胜率是单方口径+幸存者样本、第一式不可回测。
  故**每条米开规则都当作"待验证假设"**，可被证伪、可被弃用。
- **一切规则用真实数据证伪**：校准在案 → 提炼优化（带时效衰减）→
  存活的留、证伪的降权/弃。随样本累积，规则集**自然漂移，最终可能完全脱离米开，
  演化出 Claude 自有体系**。这是被允许、甚至被期待的终局。
- **靠严谨逻辑取胜，不模仿盘感**：主攻可因果验证的 **A档**（量能台阶/周期/位置/
  龙虎榜数字/止损纪律）；对不可验证的 **C档盘感**保持怀疑，不盲信。
- **诚实预判脱离方向**：米开最大的"高胜率"卖点（第一式竞价套利）恰是不可回测的 C档；
  Claude 越讲严谨，越会倚重 A档、质疑 C档——这正是长出自有体系的路径。
- 研究靶心：用严谨逻辑攻**周期、情绪、量化指标**这三块可验证的核心取胜。

## 1. 认知内核（灵魂，锚定米开 V2）

四层：**环境 → 周期 → 题材 → 情绪**，重点是**联动/过渡/拐点**（共振还是背离）。
两大命门（话语权重于其余五维）：**集合竞价**（今天能不能上、什么价上）、
**龙虎榜/席位**（钱是谁的、认不认、接力靠不靠谱）。

**★硬伤修正 1｜环境/周期是"总开关"，非七维之一。**
米开铁律"周期定仓"：量能台阶 → 连板高度 → 情绪三态**直接锁总仓位/攻防基调**
（主升8-10成 / 混沌4-5成 / 退潮0-2成）。攻防判断由这个开关驱动，不是四层平权投票。

**★硬伤修正 3｜本体系是牛市多头 beta，退潮期要自认失效。**
退潮/A杀里节点龙、穿越、套利几乎全废。系统每日自检"现在还在有效环境里吗"；
退潮期正确产出 = **喊防守/空仓、主动缩候选**，不硬凑机会。"退潮空仓就战胜99%。"

**★硬伤修正 4｜异动红线（10天100%/30天200%）全局硬过滤**（作认知，不作买卖指令）。

## 2. 架构总览（9 分支 + 1 总 agent）

**7 条功能流水线 + 2 个命门专家 + 1 总 agent。** 否决"考核/训练用户"agent（北极星已翻转为练 Claude）。

```
总 agent（编排 + 出页 + 定时 + 承接"用户圈注→复议→修订"）
  流水线 ├─ 1 取数  ├─ 2 分析  ├─ 3 校准  ├─ 4 提炼优化
        ├─ 5 认知(灵魂)  ├─ 6 推演  └─ 7 总审
  命门专家 ├─ 8 竞价命门  └─ 9 龙虎榜/席位命门
```
审查双层：每卡自审（第一层）+ 总审 agent（第二层，动态打分）。

## 3. 责任卡

### 流水线 7 张
| # | Agent | 输入 → 产出 | 自审点 |
|---|-------|-------------|--------|
| 1 | 取数 | 抓盘后+竞价真实数据 → 结构化原始池 | 完整性核验，缺标 null |
| 2 | 分析 | 原始池 → 米开语言的盘面事实（量能台阶/连板梯队/龙头/题材三要素/异动红线标记），每数据落到"这告诉操盘手什么" | 可复算、可溯源 |
| 3 | 校准 | 昨日 Claude 预判 + 今日真实结果 → 验证/错清单，逐条记在案 | 只认真实结果，不美化 |
| 4 | 提炼优化 | 累积在案 → 规则打脸降权/加权；**带时效衰减/近因加权**（硬伤7：风偏约2周被学去，过期 edge 主动降权） | 只动已在案真实反馈 |
| 5 | 认知(灵魂) | 事实+命门深读+升级知识 → 四层共振/背离/拐点，收敛成"情绪几度、明日攻防、主线续/换/散、龙头接力/退位"（攻防由总开关驱动） | 每条挂真实数据，缺料标观察点，标 A档/C档 |
| 6 | 推演 | 认知 → **Claude 每日判断/推演报告**（§7）。**必须真练**：米开式自上而下（指数→周期→主线→龙头/平铺核心）+ 历史周期类比推空间 | 预测须可被次日证伪；不给买卖点 |
| 7 | 总审 | #1–#9 产出 → 动态打分打回；**据 A档/C档界线判是否在编 C档** | 第二层门，无据/编造即打回 |
| — | 总 agent | 编排+出页+定时；承接**用户圈注→Claude 复议→修订** | — |

| # | Agent | 职责 |
|---|-------|------|
| 8 | 竞价命门 | 用米开第一式深读竞价强弱→次日预判；**第一式是 C档只能实盘**，历史拿不到925成交额排名/逐笔大单，只能训 A档代理（竞价换手8-15%、开盘位置、高开幅度→次日） |

## 4. 每日运行时流程

### 傍晚场 · 18:00（收盘后，主链路）
```
取数 → 分析(含8/9命门深读) → 校准(结算昨日Claude预判/记在案)
     → 提炼优化(吃累积在案/升级规则/时效衰减) → 认知(用升级知识判盘)
     → 推演(出Claude判断报告) → 总审(动态打分+A/C档编造检查) → 出页
```
**时序（已确认）**：先用今天真实结果**结算上一场的 Claude 预判**（核对→提炼→提升认知），
再用升级后的认知做**今天这一场**。绝不先复盘今天再倒回去比对昨天。

### 早盘场 · 9:30 前必须完成（集合竞价 9:25 收）
```
取数(竞价快照，缺数据自己想办法找) → 校准(页面更新竞价 + 对照昨晚 Claude 预判兑现)
     → 竞价命门(即时强弱) → 总 agent 更新总页面
```

## 5. 双层审查 + 动态打分（已确认）
- 第一层=每卡自审；第二层=总审 agent。
- **阈值动态、可酌情放宽**，不因差 1 分误杀有价值判断。
- 打回只针对"无据/编造/自相矛盾"硬伤；**特别据 A档/C档界线判 C档是否被事后编造**。

---

## 6. 提炼优化 + 命门历史学习（已确认）
- **大提炼攒够阈值才触发一次**；未到阈值**持续标方向**；只吃已在案真实反馈。
- **规则带时效衰减/近因加权**（硬伤7）：过期 edge 主动降权，不把上月管用的当真理。
- **历史学习（建认知）≠ 策略回测（P&L）**：不做回测；两命门历史深度学习仍可做，但**延后**（先跑通链路）。

## 7. Claude 每日判断 / 推演报告（推演终点 · v0.3 重定义）
**不给买卖点、不给止损指令、不做回测**，只呈现 Claude 的判断与逻辑：
1. **今天情绪几度**（周期五阶段哪一档）。
2. **明日攻防判断**：进攻/防守/空仓——**由量能台阶→情绪三态总开关驱动**（非四层平权）。
3. **主线站队**：主攻哪条、规避哪条、有无换线苗头。
4. **龙头/接力判断**：谁 core、谁接力、资金认不认（挂席位命门结论）。
5. **竞价强弱预判**：明日盯哪几只、什么竞价特征算强/算弱（标 C档，只能实盘验证）。
6. **次日可证伪预测**：写成明确、能被真实结果打脸的命题。

**推演须真练**（硬伤5）：自上而下正推 + 历史周期类比，不是填字段。
次日由校准 agent 逐条结算 Claude 自己的预判：对了加权沉淀、错了记账降权——**这就是 Claude 的训练回路**。
用户可对任意一条**圈注歧义**→ Claude 复议 → 认可则修订，否则以 Claude 判断为准。
